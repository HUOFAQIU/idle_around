## 1. 暴击、伤害、护盾与异常结算（唯一权威节）

- **数值落地口径**：中间计算允许小数（暴击倍率、比例、冷却等），但写入属性的伤害/治疗/护盾/状态数值**统一向下取整**；`DamageResolver` 入口、各 Execution（`floorf`）与属性集 `pre_attribute_change()` 均做取整（不可仅在属性层取整，否则 7.5 会扣 8）。
- **暴击规则**：`AutoCastAbility` 对每个目标独立掷暴击写入 `Data.CritMultiplier`（不暴击 1.0）；暴击时 execution 注入 `GameplayTags.Event_Combat_Critical` 供日志与飘字上样式。**异常状态仅在施加时判暴击**，后续周期每跳不再暴击。
- **执行器与分流**：
  - 直接伤害（`SoulDamageExecution`）：`damage = floor((base_damage + damage_bonus) × crit_multiplier)`，经 `DamageResolver.split_damage()` 先 1:1 扣护盾再扣生命。
  - 伤害+剧毒（`PoisonDamageExecution`）：直伤后再按 `poison_ratio`（默认 1）转整数剧毒（不足 1 保底 1）。
  - 护盾（`ShieldExecution`）：`floor(base_shield × crit)`，不吃 `damage_bonus`。
  - 治疗（`HealExecution`）：`heal = floor(base_heal × crit)`，同时净化 `floor(heal × 5%)` 点 `burn` 与 `poison`（生命再生不触发净化）。
  - 灼烧（`BurnTickExecution`，每 0.5 秒，3% 衰减）：总伤入口取整，对护盾伤害减半再取整，破盾后按「1 护盾抵 2 灼烧」转生命；归零后在 `periodic_effect_ticked` 移除 `burn_tick` 与 `State.Burning`/Cue。
  - 剧毒 vs 生命再生（`NetStatusTickExecution`，每秒不衰减）：先整数相减按净值差结算（剧毒无视护盾、生命再生溢出丢弃、相等不结算），原值/标签/状态条保留；剧毒清零移除 `poison_tick` 与 `State.Poisoned`/Cue。
- **信号与生命周期坑**：普通伤害/治疗走 `ASC.effect_received`，周期每跳走 `periodic_effect_ticked`，血条/死亡/半血触发器走 `attribute_changed`。致命一击飘字改挂战场单位层防随目标销毁；`CombatNames.source_name()` 与 `SoulDamageExecution._source_asc()` 取来源前必判 `is_instance_valid()`（来源已死显示「未知来源」）。

## 2. 冻结语义

- `State.Frozen` 为单位级标签（`freeze_unit.tres`，默认 1s `DURATION` + `Cue.Status.Freeze`，可被 `effect_duration` 覆盖），锁整个单位的充能、释放与移动；`ChargedAbility.freeze_units` 为魂灵级，仅停单颗魂灵。
- 两种冻结均只停自然充能与释放：外部 `add_charge()` 仍有效，加减速/冻结计时照常倒数，不中断已发射投射物或已进入吟唱的技能；解冻后充能满且 20 刻锁走完即刻释放。

## 3. 玩家与怪物无场景构建契约

两者均由 `BattleUnit.create_headless(team)` 纯代码构建为轻量 `Node`（无 2D 场景与碰撞体），共走 `setup_from_scene(passive_effects)`：
- **玩家**（`team=PLAYER`）：挂 `PlayerStatsAttributeSet`（含 `damage_bonus`），技能全来自 `vessel_cells` 魂器；`unit_name`/`max_health` 由 `BattleSession` 从 `PlayerProfile` 注入。
- **怪物**（`team=ENEMY`）：挂 `MonsterStatsAttributeSet`，数值、魂灵、掉落与 3D 表现（`mesh_3d`、`anim_config`）全部来自 `MonsterData`；射程外且无持续效果时 `ASC` 自动休眠。

## 4. 开战、关窗与死亡流程

- **开战（05 面地图按钮 → `BattleWindow.start_battle()` → `BattleArena.start_run()` → `BattleSession.start()`）**：先 `stop()` 清场并 `run_id += 1`（作废旧重开等待）→ 新建 `BattleManager` 并先挂遥测/信息窗/控制台观察者 → 读 `vessel_cells` 魂器网格生成玩家放 `(0,0)` → `CombatTelemetry.begin_run()` → `BattleManager.begin()` → `MapRun.take_initial_spawns()` 立刻刷首怪（计入时间配额）→ `battle_started` 开扫描线。
- **关窗**：`hide()` → `visibility_changed` → `BattleSession.stop()`（`run_id += 1`、清场、关扫描线）。
- **死亡与完成**：`_queue_death()` 延迟一帧确认（让伤害日志先出，同帧回血不死）→ `_die()` 挂 `State.Dead`；怪物死后掷掉落移名册并计入 `MapRun.on_monster_killed()`（测试刷怪不计数），尸体由 `BattleSession` 回收进对象池（上限 `MAX_ENEMY_POOL = 512`，`activate_from_pool()` 重置属性与挂点后复用，池满或已停战才 `cleanup_asc()` + `queue_free()`）；玩家死后等 `REVIVE_DELAY = 3s` 重开，全清地图后等 `MAP_RESTART_DELAY = 5s` 重开（关窗/换图改变 `run_id` 立即作废等待）。
