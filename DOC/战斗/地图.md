# 地图物品

- 地图是物品，占 2×2，`category = "MAP"`，卡面文字「地图：森林」。
- 实例是 `MapItemData`，挂一份 `MapData`；tooltip 标题显示地图名「森林」，正文按刷怪配置生成。
- 地图不消耗。角色可以无限死亡，每次重开都从这张图的第一只怪开始。

# 05 面地图板

3×3 网格，中心是投放槽，周围 8 个地图按钮：

```text
槽0 槽1 槽2
槽7 投放 槽3
槽6 槽5 槽4
```

槽位 0～7 从左上角起顺时针；空槽不显示按钮，只有放进去的地图才生成按钮。

## 放入

1. 仓库左键拿起地图，点 05 面中心槽。
2. 有空格：地图从槽里消失，飞向顺时针第一个空槽并变成按钮。
3. 8 格满：地图留在中心槽，提示「地图集已满」；中心已有地图时再放会被拒绝，地图留在手上。
4. 点击中心槽里的地图可以重新拿起，放回仓库。

某个按钮被 ⬇ 退回后，中心槽里的地图会自动飞进空出的槽位。

## 地图按钮

- 主按钮显示「地图：森林」，悬停显示地图 tooltip。
- 左键：打开战斗窗口并立刻开战。同一张图已经在前台时只置顶；点另一张图会停掉当前战斗并换图。
- 右上角 ⬇：退回仓库。仓库满时地图留在原槽并提示；如果这张图正在战斗，先停战并关窗。

## 锁面

05 面和 02 面一样，只在有活动存档（`IN_GAME`）时解锁。

# 刷怪配置

`MapData.spawn_entries` 每个条目是一条 `MapSpawnEntry`：

| 字段 | 说明 |
|---|---|
| `condition` | `TIME_INTERVAL` 按时间刷；`KILL_COUNT` 按击杀条件刷 |
| `monster_id` | 刷出的怪物 `content_id` |
| `count` | 时间条目的总量；击杀条目填 0 |
| `interval_seconds` | 时间条目的间隔（秒） |
| `kill_monster_id` | 击杀条件统计哪种怪 |
| `kill_threshold` | 每累计击杀多少只触发一次 |

森林的配置：

```text
蛇，200，每 1 秒
蝮，0，每累计击杀 10 蛇
```

- 蛇整张图总共刷 200 只，每 1 秒 1 只；开战立刻刷的第一只也算在 200 里。
- 蝮没有独立配额，只由「每累计击杀 10 蛇」触发；被击杀的蝮不计入蛇的击杀数。
- 测试接口刷出的怪不计入地图击杀数，避免干扰完成判定。

工具生成的 tooltip：

```text
森林

每 1 秒出现蛇
每累计击杀 10 蛇时，出现蝮
```

# 完成与重开

- 完成条件：所有时间条目配额刷完 + 没有排队待刷的怪 + 场上没有存活怪物。
  最后一杀触发的蝮也算排队怪，必须刷出来并击杀。
- 完成后打日志，等待 5 秒自动用同一张图重开；配额和击杀计数全部重置。
- 角色死亡沿用现有 3 秒重开，整张图从第一只怪开始。
- 关窗、点 ⬇ 退回、换图都会中止本场，下次点这张图从头开始。
- 战斗进度不存档；读档后地图板恢复，战斗从新一场开始。

# 数量石

- 数量石是 1×1 物品，`category = "STONE"`，卡面文字「数量石」，tooltip「怪物数量 +50%」。
- 当前只做物品、仓库和 tooltip：没有使用功能，不能放进地图板，也不会被消耗。
- 数量石功能实装时：只乘 `TIME_INTERVAL` 条目的 `count`，不影响 `KILL_COUNT` 刷出的怪；地图 tooltip 在条件行后空一行显示「怪物数量 +50%」。

# 数据与内容

- `MapData`：`content_id`、`display_name`、`icon`、`spawn_entries`。
- `MapSpawnEntry`：刷怪条件、怪物 id、数量、间隔、击杀目标/阈值。
- 森林资源：`base_mods/core/maps/forest/forest_map.tres`。
- 数量石资源：`base_mods/core/items/quantity_stone/quantity_stone.tres`。
- 地图和数量石暂时硬编码在 `MapCatalog`，不进 mod manifest；加新地图时在 `MapCatalog` 登记 id 和资源路径。
- 旧的全局随机刷怪和「每 10 只常规怪刷稀有」规则已删除；`MonsterData.spawn_weight` / `is_rare` 也一并删除，刷什么怪完全由地图配置决定。
