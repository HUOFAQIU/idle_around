# 装备

## 需求
- 每件装备都有自己的魂灵
- 装备目前就定这六件：武器 / 头部 / 身体 / 鞋子 / 项链 / 戒指
- 装备掉落现在还没写，不急
- 在仓库里可以多生成几件不同的装备和魂灵
- 当仓库窗口和装备窗口打开时，在仓库内右键装备时，会自动替换掉当前装备，若当前装备放置了其他魂灵，则将其他魂灵放入仓库窗口的临时页
- 临时页内的装备和魂灵只能取，不能存，临时页按钮用红色标识

## 从装备面板那张图上补的需求
- 面板六行，每行：左边是**部位槽**（放那件装备），右边是**魂灵区**
- hover 魂灵浮出技能提示：名字 / 释放频率（秒）/ 技能描述
- 魂灵格上有**冷却扫描线**：从下往上走，到顶时「释放技能」，然后重新读 CD

## 需求里没写、后来定下来的
| 问题 | 定下来的做法 |
|---|---|
| 魂灵区多大 | **一排 10 格宽、高 2 格**；「10 格」是**横向占位上限**——魂灵按自己的宽度占，加起来最多 10 格 |
| 魂灵多大 | 魂灵也分**大中小**（大 3×2 / 中 2×2 / 小 1×2）。跟装备不是同一套尺寸，各在各的类里 |
| 怎么放 | **像仓库放东西一样**，不是 10 个分开的格子：整片区域连续，魂灵落在哪一列都行，只要不越界、不重叠 |
| 扫描线到顶真的造成伤害吗 | 先只做视觉，不接战斗 |
| 换下来的旧装备去哪 | 连同它身上的魂灵一起进仓库临时页 |
| 魂灵怎么装上去 / 取下来 | **拖拽**（暗黑 2 那样）；装备面板既能接也能往外拖 |
| 装备怎么换 | **只能在仓库里右键**；拖不过来（2026-09-21 定的，装备槽不接拖拽） |
| 装备怎么卸 | **右键装备槽** = 卸下，那件连同魂灵进仓库临时页（2026-09-21 定的） |
| 换下来的旧装备去哪 | 连同它身上的魂灵一起进仓库临时页（顶下来、右键卸下来，都是这条路） |
| 面板里画多大 | 跟仓库一样，**一格 32 像素**（`InventoryItem.CELL_SIZE`） |
| 面板长什么样 | **一行一个 SlotCell 组件**（`slot_cell.tscn`），六行在编辑器里摆好 |

## 现在是什么样【已定】

相关文件：`Windows/Equipment/` 下 `equipment_window.tscn`（窗口）+ `equipment_panel.gd`（面板：只管数据与落点）+ `slot_cell.tscn` / `slot_cell.gd`（一行组件）+ `Windows/Equipment/equipment.gd`、`Windows/Inventory/soul.gd`（数据）。
长什么样归 `Scripts/item_view.gd`（挑 `Tokens/` 下的场景）+ `Kits/Tooltip/soul_tooltip.tscn`（魂灵提示框）

```
EquipmentWindow  432×790
└─ Panel   EquipmentPanel（VBoxContainer）
   ├─ SlotCell  一行一个，六行，从上到下：武器 / 头部 / 身体 / 鞋子 / 项链 / 戒指
   │  ├─ SlotLabel        部位名（代码按顺序填）
   │  └─ HBoxContainer
   │     ├─ EquipmentSlot 装备槽 96×96（装备 1:1 居中摆）
   │     └─ SoulPanel     魂灵区 320×64 = 10 格 × 2 格 @32 像素
   └─ …
```

| 项 | 值 | 在哪 |
|---|---|---|
| 六个部位 | 武器 / 头部 / 身体 / 鞋子 / 项链 / 戒指 | `Equipment.Part` |
| 一行的尺寸 | 416×126（标签 30 + 底下一行 96） | `slot_cell.tscn` |
| 装备槽 | 96×96 | `SlotCell` 的 `EquipmentSlot` |
| 魂灵区 | 10 格宽 × 2 格高 = 320×64 像素，横向占位上限 10 格 | `Equipment.SOUL_AREA` |
| 装备尺寸 | 大 2×3 / 中 2×2 / 小 1×2 | `Equipment.SIZE_CELLS` |
| 魂灵尺寸 | 大 3×2 / 中 2×2 / 小 1×2（小魂灵就是 32×64） | `Soul.SIZE_CELLS` |
| 放置规矩 | 在魂灵区里、不和已装的魂灵重叠 | `Equipment.can_place_soul()` |
| 冷却 | 扫描线 0→1 走完 `cooldown_seconds` 秒，到顶归零重来 | `SlotCell.cooldown_seconds` + `Soul.cd_progress` |

- **分工**：`slot_cell.gd` 自己管一行的全部——挂装备和魂灵的视图、hover 提示、拖拽起落；`equipment_panel.gd` 只管「哪个部位装了哪件」和把落点转发给鼠标底下那一行
- **装备槽**：装备按自己的格数 1:1 摆（大件 64×96 也放得下，不缩小），在 96×96 的槽里居中；格子上不写名字
- **魂灵区**：一整片连续区域，每 32 像素一条竖格线（一眼看出横向 10 格）；魂灵按自己的位置和大小摆着
  - 格线画在 `SoulPanel` 自己的 `_draw()` 里——父节点画的在子节点**底下**，正好被魂灵压住；冷却线、hover 框、落点框则要压在魂灵**上面**，所以归 `SoulOverlay` 那一层
- **扫描线**：魂灵自己那块底下按进度往上填一层半透明黄，顶上一条亮线；走满就重来（`slot_cell.gd::_draw_cooldown()`）
- **魂灵提示**：hover 魂灵浮出提示框（`Kits/Tooltip/soul_tooltip.tscn`）：版面就是**场景自己的样子**（名字 + 冷却秒数 + 技能说明），代码只把 `NameLabel` 换成魂灵的名字
  - 冷却秒数和技能说明现在还是场景里**写死的占位文字**——这俩数据还没有：`Soul` 只有进度 `cd_progress`，时长还挂在 `SlotCell.cooldown_seconds` 上（**面板级**的，每颗魂灵不能各是各的）。等数据模型定下来再往那两个 Label 里填
  - `SkillPanel` 得是 **`PanelContainer`**（不是 `Panel`）：`Panel` 只认自己的 `custom_minimum_size`、**不认里面子节点要多大**，提示框会按「名字」算宽度（实测 48），冷却和说明就溢出到框外面去了。它还挂了个空 `StyleBoxEmpty`，免得在深色提示框里又画一层引擎默认的浅色面板
  - 跟着鼠标走、贴边翻向
  - 提示框挂在**窗口**上（挂在行里会被 VBoxContainer 当成新的一行排版）；挂在窗口上就意味着**超出窗口的部分会被裁掉**，所以翻完还要再夹回窗口里（`TooltipBase.place_near()`）
  - **头一次 hover 才建**：`_ready()` 那会儿窗口还在搭自己的子节点，往它身上 `add_child()` 会被拒
- **落点预览**：拖着魂灵时按指针位置算出落点，放得下画**绿框**、放不下画**红框**；框画的就是收边之后的落点
  - **判定放得宽**：落在**这一行**上就算（部位名、装备槽上都收），落点横竖都夹进魂灵区——往右拖过头一点松手，就落在还放得下的最靠右那一格（`SlotCell._drop_cell()`）
- **右键换装**（在仓库里，且装备窗口开着）：装备直接换到对应部位；部位对不上的不理会。
  **装备只能这么换，不能拖**：装备槽不接拖过来的装备（部位对得上也不收），拖着装备过来只会跟着鼠标走、不画落点框
- **右键装备槽 = 卸下**（`SlotCell.unequip()`）：槽清空，那件连同它的魂灵进仓库临时页；空槽右键什么也不做，手上正拖着东西时也不卸
  - 卸下和「被顶下来」走的是同一个信号 `equipment_removed`，仓库窗口接住后统一丢临时页
- **拖拽**：只有魂灵能拖 —— 魂灵拖到魂灵区里装进去，或者从魂灵区里拖出去
  - 装备连仓库窗口都出不去：在仓库里拖着挪位置可以，鼠标一离开仓库窗口这次拖动作废、回原位（`inventory_grid._cancel_drag()`；`GameGlobal.dragged_item_can_leave()` 是这条规矩的判定）
  - 拖拽靠 `GameGlobal.dragged_item` + `drop_target` 分组找落点，两个窗口都能当落点
  - 落点先按**屏幕坐标**确认鼠标真在这个窗口里（`GameGlobal.mouse_in_window()`）——鼠标跑到别的窗口上时，那个窗口记的还是上次离开的位置，不这么判会落到错的地方
  - 落在放不下的地方就回原位；魂灵拖出装备后放不下也会回原来的格子
  - **在魂灵区里能随便挪**：按住一颗魂灵拖到本行别的格子、甚至拖到别的部位那件装备的魂灵区上，松手就落在新位置
  - **手上那件东西鼠标走到哪儿都看得见**，三层接力：窗口里铺的一层（`Scripts/drag_overlay.gd`，铺满整个窗口，鼠标在窗口里都由它摆）→ 出了窗口交给无边框小窗口（`Scripts/drag_ghost.gd`）→ 落点框还是各行自己画（只有魂灵区那一小块）
	- 装备窗口里能接东西的只有魂灵区那一小块，鼠标移到部位名、行距、边距上时那些控件都管不着，所以必须有一层铺满窗口的兜底，不然东西会凭空消失
  - **松手那一下 `GameGlobal.drag_ended` 会让画过它的地方重画一遍**：这几处平时只在拖动途中重画，不擦的话最后一帧（比如放不下的那颗魂灵、红框）会留在原地
  - **落点按「抓在哪儿」对齐**（`GameGlobal.dragged_offset`）：抓着魂灵的哪一块拖，松手它就落在那一块对着的格子上
- **临时页**：仓库多了最后一页，里面堆换装换下来的旧装备和旧魂灵
  - 按钮是红的（字是「临」），页空着的时候按钮藏起来
  - **只能取不能存**：往临时页里拖东西会被拒（`can_place()` 直接返回 false），只有换装顶下来的东西会自动进去

## 还没做【待写】
- **装备掉落**：现在仓库里那几件是写死的演示数据，名字和魂灵都是编的
- **魂灵美术**：`Tokens/Souls/soul_*.tscn` 现在就一个 `ColorRect` 底（深灰，跟装备 token 一个色），等着画
- **装备 / 魂灵数值**：伤害、释放间隔这些已经全部去掉了（只做视觉和功能），
  等掉落和战斗接入时再定；扫描线的节奏现在是装备面板上的一个固定值（`SlotCell.cooldown_seconds`），
  所以同一行里所有魂灵的扫描线同步走
- **技能不接战斗**：扫描线走满只是视觉，不会真的对敌人造成伤害（战斗窗口那边玩家还是自己每 2 秒射一箭）
- 品质 / 品阶 / 随机词条 / 强化，一个都还没做
- 魂灵区的上限是定死的 10 格：能不能扩容、能不能把魂灵合成 / 升级都还没定
