# 仓库

像《暗黑破坏神2》那样的装备仓库，写在 `Windows/Inventory/inventory_window.tscn` 下（相关脚本都在 `Windows/Inventory/` 这个文件夹里）。

## 需求
- 仓库有很多页，目前共 5 页，每页大小 50\*50，每格 16\*16。分页在仓库左上方。
- 装备分大中小，大型 3\*2，中型 2\*2，小型 1\*2。
- 仓库第一页内有大中小各一件装备，不需要设计装备细节，用色块表示就行。
- 装备可以被拖动。鼠标左键对物品长按时，随鼠标移动可以拖动装备，松开时放下当前装备。
- 不需要写本地存档，还没到时候。
- 设计不要复杂，简单明了就行。

## 后面加的需求
- 鼠标 hover 装备时浮出**详情面板**：名字 / 物理伤害 / 魂灵（魂灵也得能看见）
- 格子里的装备本身也写上名字（放不下就不写）
- 和装备面板互通：右键换装、拖拽，详见 `equipment.md`
- 换装换下来的东西不能丢，得有个地方堆——多了个**临时页**

## 2026-09-28 改过的
- **装备数值和魂灵数值都去掉**：装备不再有物理伤害，魂灵不再有释放间隔 / 技能描述。
  显示出来的只剩名字，数值等掉落和战斗接入时再定
- **大件从 3×2 改成 2×3**：装备现在是 大 2×3 / 中 2×2 / 小 1×2（魂灵还是 大 3×2 / 中 2×2 / 小 1×2）
- **格子上不写名字了**：怎么画归 `Tokens/` 下的场景管，场景里没有 Label。
  名字在 hover 提示框里看。想让名字回来，往 token 场景里加个 Label 就行
- **hover 提示框少了「物理伤害」那一行**（没这个数值了），魂灵区也改成 1:1 显示

## 现在是什么样【已定】

```
InventoryWindow  (extends BaseWindow)
└─ MarginContainer  边距 16
   └─ VBoxContainer  间距 12
	  ├─ Pagination  左上角的分页按钮（HBoxContainer）
	  └─ Grid        InventoryGrid，单元格 800×800
```

| 项 | 值 | 在哪 |
|---|---|---|
| 每页格数 | 25 × 25（= 800×800 像素） | `InventoryGrid.PAGE_CELLS` |
| 每格像素 | 32 × 32 | `InventoryItem.CELL_SIZE`（仓库和装备面板共用这一格） |
| 页数 | 5 个普通页 + 1 个临时页 | `inventory_window.gd::PAGE_COUNT` |
| 物品尺寸 | 装备 大 2×3 / 中 2×2 / 小 1×2；魂灵 大 3×2 / 中 2×2 / 小 1×2（**宽 × 高**） | `Equipment.SIZE_CELLS` / `Soul.SIZE_CELLS` |
| 窗口大小 | 832×875，跟着内容算（`popup_centered()`） | `inventory_window.tscn` |
| 提示框里的魂灵区 | 一排 10 格 = 320×64 像素（跟装备面板一样 1:1） | `Kits/Tooltip/equipment_tooltip.tscn` + `.gd` |

- **物品**（`inventory_item.gd`）：只记「左上角格子 + 尺寸 + 名字」。
  装备额外带**部位**和**魂灵区**（`equipment.gd`），魂灵带**冷却进度**（`soul.gd`，进度推多快归装备面板的 `cooldown_seconds`）。
  尺寸表下放到两个子类：大中小对装备和对魂灵不是同一套尺寸，所以 `cells()` 由子类各自覆盖。品质、词条、强化这些还没设计
- **网格**（`inventory_grid.gd`）：底板和格线还是 `_draw()` 一次画出来的，没建 2500 个节点；鼠标悬停会勾出当前格子。
  物品本身是挂在网格下的 `ItemView` 子节点（见下）
  - **悬停高亮画在 `_draw()` 里，不归 `_overlay` 那层**：父节点画的在子节点**底下**，东西压上去正好把它挡住
    （魂灵占 2×2 格，悬停其中一格时白框有两条边落在它身上，压在底下才不会被看见）。
    空格子上没东西挡，所以照样看得见。`_overlay` 只留**拖动落点框**——那个必须压在最上面，挡住就没法预览了
  - 装备面板那边不一样：那儿的高亮框勾的是**魂灵自己**（不是格子），是「你指着的是这颗」的提示，所以仍然压在魂灵上面（`slot_cell.gd`）
- **一件东西长什么样**：`Scripts/item_view.gd` 按大小挑 `Tokens/Equipments/`、`Tokens/Souls/` 下的场景，
  场景自己带美术。格子上的名字没有了——场景里没 Label，名字看 hover 提示框
- **hover 提示框**（`Kits/Tooltip/`，**装备一个、魂灵一个**，按 hover 到的东西二选一）：鼠标指到东西就浮出来、跟着鼠标走，靠近边缘会自动翻到另一侧
  - 装备走 `equipment_tooltip.tscn`：名字 + **整片魂灵区**（10 格 1:1，每颗魂灵按自己的位置和大小摆着）
  - 魂灵走 `soul_tooltip.tscn`：**照场景自己的版面**（名字 + 冷却秒数 + 技能说明），代码只填 `NameLabel`；冷却和说明现在还是场景里的占位文字（数据还没有）
  - 贴边翻向 + 夹回窗口那套在 `TooltipBase.place_near()`（`Kits/Tooltip/tooltip_base.gd`），两个提示框共用；同一时刻最多浮出来一个（`InventoryGrid._visible_tip()`）
  - **底色是自己在 `TooltipBase._style_panel()` 里给的**（深色 + 1 像素边框），不在各自的 `.tscn` 上写。理由：引擎默认主题给 `PanelContainer` 的是一块**浅色**面板，压在同样的浅色美术上就看不出边界了——魂灵提示框曾经是 `(255,248,225)` 压在魂灵 token 的纯白 `(255,255,255)` 上，看着就跟「没弹框」一样。样式给在一处，以后加第三个提示框也不会漏
  - 里面每个节点都 `mouse_filter = IGNORE`，否则它跟到指针底下会把 hover 顶掉
- **分页**：5 个页码按钮，一组 `ButtonGroup` 单选，当前页高亮；拖着东西划过页码按钮就翻页
- **放置规则**：`can_place()` 挡掉越界和重叠，`add_item()` 返回放成功没有
- **拖动**：左键按在装备上就把它从页里摘下来拿在手上、跟着鼠标走；松手时放得下就落地，放不下（重叠 / 往临时页里放）自动回原位
  - 拖动中在落点画框：**绿框**放得下、**红框**放不下；**框画的就是收边之后的落点**，看到框在哪就是落在哪
  - **落点会整件往页里收**（`_clamp_into_page()`）：往右（或往下）拖过头，东西落在还放得下的最靠边那一列，不会因为「越界」整个弹回原位
  - **鼠标落在窗口里就算数**：不要求正好指在格子上，分页栏、四周那圈边距上松手也收，就近夹进边上那一格
  - 松手在网格外面也算数（`_process()` 里查左键状态），不然拖到窗口别处松开会卡在手上
  - 一次只拖一件：手上还有东西时不再接新的一次按下，免得前一件被顶掉
  - **装备拖不出仓库窗口**：鼠标一离开窗口，这次拖动直接作废、东西回原位（`_cancel_drag()`）。
    魂灵不在此列——它还得拖到装备窗口去
  - **手上那件东西鼠标走到哪儿都看得见**：仓库窗口里由窗口上铺的那层 `Scripts/drag_overlay.gd` 摆
    （装备只能在仓库里挪，那层也是唯一要看装备的：`allow_equipment = true`）；出了窗口交给 `Scripts/drag_ghost.gd` 那个无边框小窗口（每个窗口只画得了自己的画布，详见 `equipment.md`）
  - 手上那件怎么画，跟格子里那件一样都走 `Scripts/item_view.gd` —— 一处说了算
  - **落点按「抓在哪儿」对齐**（`GameGlobal.dragged_offset`）：抓着装备的右下角拖，松手时它就落在右下角对着的格子上，不会跳到指针正中
- **跨窗口**：拖着东西时装备面板也能当落点（靠 `drop_target` 分组），反过来装备面板拖出来的魂灵也能落回仓库
- **右键换装**：装备窗口开着时，右键仓库里的装备 = 换上；被顶下来的旧装备连同它的魂灵进临时页
- **临时页**：最后一页，按钮红色标「临」，空着就藏起来；**只能取不能存**
  - 里面堆的是从装备窗口出来的东西：换装顶下来的旧装备、在装备窗口里**右键卸下来**的装备，以及它们身上的魂灵（`equipment_removed` 信号 → `_on_equipment_removed()`）
- **演示数据**（`inventory_window.gd::_fill_demo_page()`）：第一页摆六件装备 + 三颗散魂灵，名字都是占位编的
  - 弓（中 2×2）身上装着「弓手（中）@第 1 格」+「石肤（大）@第 3 格」
  - 锁子甲（大 2×3）身上挂着「疾风（小）@第 5 格」
  - 皮帽 / 软靴 / 护身符 / 铜戒 空着
  - 散着的：剑士（小 1×2）、狼魂（中 2×2）、巨力（大 3×2）
