1、去掉主菜单魂灵按钮，去掉魂灵窗口，整合进角色窗口。

2、角色窗口（同 Tooltip 文本显示方法）
```
小煤灯（角色名）


生命值：500 / 500

===================================
(横着摆 3 个魂器槽)
```

3、取消魂灵部位要求，添加大小。
```
恐狼
[ 中型 ][ 狼 ][ 动物 ]

暴击率，0 %
攻击距离，2
===================================
( 6 秒 )
> 对最近的怪物造成 30 伤害

- 每有一个狼，此魂灵+10 点伤害
===================================
```

4、添加魂器，魂器是装魂灵的容器。不同魂器有自身特效，有自身空间大小。

5、魂器应该分为战斗用和工具用，战斗用可装备在角色身上。

6、角色可装备多个魂器，现在预留 3 个槽

7、右键点击魂器，会打开相应的窗口，就像之前魂灵窗口那样。

8、举两个例子
战斗用

煤油灯
物品大小，2*2
容器大小，6*2
