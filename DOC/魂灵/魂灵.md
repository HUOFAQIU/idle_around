# 魂灵

魂灵是能装备的，装备在魂灵窗口。

魂灵是分部位的，角色身上目前有 4 个部位，各有自身的功能趋向
1、头，充能
2、身，防御
3、手，伤害
4、腿，加速


# 规范描述
主动魂灵都拥有冷却，冷却结束会释放技能，技能拥有至少一个效果。主动魂灵也会有触发效果。
（实现状态：`SoulData.triggers` 主动/被动魂灵通用；属性型 `passive_effects` 仍只有 PassiveSoulData 支持。）
被动魂灵拥有被动效果或者是至多 6 条属性，这两者不会同时存在。

# 类型
魂灵可以带类型（`SoulData.types`，`StringName` 数组），用于让特定效果只在这些魂灵上触发；类型按需配置，不强制每颗魂灵都有。
类型不做层级分类，直接用 `Soul.types` 前缀。

例如，恐狼同时带 `Soul.types.Wolf` 和 `Soul.types.Animal`；当前只有它带类型。
类型中文名统一在 `Scripts/soul_text.gd` 的 `SoulText.TYPE_NAMES`，tooltip / 见闻 / 调试共用；未知类型回退到 ID 最后一段。


# 标签
每个魂灵都有标签，用于作为见闻窗口的筛选功能，能筛选相应标签的魂灵，快速检索。
直接用 `Soul.tags` 前缀。

能够造成伤害的具有`Soul.tags.Damage`，`Soul.tags.DamageReference`
能够造成灼烧的具有`Soul.tags.Burn`，`Soul.tags.BurnReference`
等等
其他类似也一样

当前实现的效果标签：`Soul.tags.Damage` / `Soul.tags.DamageReference`、`Soul.tags.Burn`、`Soul.tags.Poison`、`Soul.tags.Freeze`、`Soul.tags.Heal`、`Soul.tags.Regen`、`Soul.tags.Shield`、`Soul.tags.Haste`、`Soul.tags.Slow`、`Soul.tags.Charge`。Reference 表示与对应效果相关但不直接产生该效果。


## 尺寸

按占格宽度判定，所有魂灵都带且只带一个尺寸标签：

`Soul.tags.Small`
`Soul.tags.Medium`
`Soul.tags.Large`

当前卡面按尺寸统一使用 `Assets/soul_small.png`、`soul_medium.png`、`soul_large.png`；魂灵名称由 `ItemView` 的 `SoulNameLabel` 叠在卡面上，背包、装备槽、拖拽幽灵三处一致。


## Tooltip

鼠标悬停在魂灵卡面上时显示；标题（魂灵名）用大字号，正文由 `Windows/Tooltip/soul_tooltip.gd` 的 `SoulTooltip.build()` 统一生成：

```
[ 类型名 ][ 类型名 ]        ← 可选，按 soul.types 显示；中文名来自 SoulText.type_name
(空行)
暴击率，<crit_chance × 100> %
攻击距离，<技能 TargetRule.max_range；非 TargetRule 为 0>
===================================
<SoulData.tooltip_blocks[0]，其中 {cooldown} 已替换成冷却>
===================================
<SoulData.tooltip_blocks[1]>
===================================
...
===================================
{ 部位 }                    ← 可选，equip_part != ANY 时显示
```

- 类型行按 `SoulData.types` 的顺序显示，中文名由 `SoulText.type_name()` 提供；没有 `types` 就不显示。
- 正文段落来自 `SoulData.tooltip_blocks`，格式化器用 `===================================` 连接；`{cooldown}` 会替换成技能冷却。
- 没有 `tooltip_blocks` 的魂灵只显示头部 + `无`。
- 分隔线由格式化器插入，标点为中文全角，数字去掉小数尾零；新增魂灵只填数据，不改 UI 代码。
- 恐狼的文案全部在 `kong_lang_soul.tres` 的 `tooltip_blocks` 里，技能资源不再存展示文本。
- 见闻窗口的魂灵条目也复用同一份 tooltip；未遇见条目不显示。

```text
tooltip_blocks = Array[String]([
	"( {cooldown} 秒 )\n> 对最近的怪物造成 30 伤害\n\n- 每有一个狼，此魂灵+10 点伤害",
])
types = [&"Soul.types.Wolf", &"Soul.types.Animal"]
```

类型中文名不在魂灵资源里重复填；在 `Scripts/soul_text.gd` 的 `TYPE_NAMES` 里维护一次，所有界面共用。

正文控件是 `RichTextLabel`，`SoulTooltip.build(soul, colored = true)` 会返回 BBCode 并按 `GameColors` 全局色板给状态词上色；色板同时供战斗日志、头顶飘字、状态条使用，定义在 `Scripts/game_colors.gd`：

| 关键词 | 颜色 |
|---|---|
| 伤害 | `#f5503d` |
| 灼烧 | `#ff9f45` |
| 剧毒 | `#0ebe4f` |
| 加速 | `#00ecc3` |
| 减速 | `#cb9f6e` |
| 充能 | `#00ecc3` |
| 生命再生 / 再生 | `#8eea31` |
| 治疗 | `#8eea31` |
| 暴击率 / 暴击 | `#f5503d` |
| 冻结 | `#3fc8f7` |
| 护盾 | `#f4cf20` |

- 长词优先匹配（`生命再生` 不会被拆成更短的词）；标题、类型行、攻击距离、部位行不参与状态词上色。
- 分隔线使用暗色 `#4a4f58`；`( X 秒 )` 冷却行放大到 20 号字（标题 24、正文 16）。
- `暴击率，X %` 整行使用暴击色 `#f5503d`，其余行只给关键词上色。
- BBCode 模式下正文里的 `[` / `]` 会转义成 `[lb]` / `[rb]`，保证 `[ 狼 ]` 按原文显示。
- `SoulTooltip.build(soul)` 默认返回纯文本，供测试或非 BBCode 界面使用。
