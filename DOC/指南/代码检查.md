## 一键命令

在项目根目录用 Git Bash：

```bash
bash tools/check.sh --file Scripts/foo.gd   # 单文件文本规则，最快
bash tools/check.sh --staged                # 暂存文件 + 全量编译检查
bash tools/check.sh --all                   # 单测 + 全量文本规则 + 编译检查
```

若 Godot 不在默认路径，先 `export GODOT_BIN=".../Godot_v4.7.2-stable_win64_console.exe"`。

首次使用装一次 git hook：

```bash
bash tools/install.sh
```

它把 `core.hooksPath` 指到 `tools/git-hooks/`：提交跑 `--staged`，推送跑 `--all`。Claude Code 的 `PostToolUse` hook 在每次 Edit/Write 后跑单文件规则，把错误回传给模型；硬门仍是 pre-commit 和 CI。

## 规则

Python 规则（`tools/lint/rules.py`）：

| ID | 检查 | 级别 |
|---|---|---|
| `comment-marker` | `#` 注释里的 TODO/FIXME/HACK/暂时/先这样/以后优化 | error |
| `commented-code` | 整行注释掉的代码 | warning |
| `resource-name-cjk` | `.gd/.tscn/.tres` 中的中文 `resource_name` | error |
| `file-access-boundary` | `FileAccess`/`DirAccess` 出 `Scripts/save/`、`Scripts/mod/`、`Scripts/debug/`、`modkit/` | error |
| `mod-path-root` | 裸写 `res://base_mods`、`user://mods`、`res://mods` 根路径 | error |
| `inline-color` | 表达式里内联 `Color(...)` 字面量；命名常量/声明不受影响 | error |

注释策略：

- `##` Godot 文档注释和 `#region` / `#endregion` 白名单。
- 普通 `#` 注释写事实（为什么、边界、引擎行为），不写"先这样/够用"。
- 不做"删光注释"：当前 308 行普通注释里 114 行是 region、193 行是事实注释，直接删会丢 why。

Godot 警告（`project.godot` 的 `[debug]`，值 `2` 表示提成 error）：

- 4.7 中除下面几类外的警告全部提成 error。
- 未启用：`unsafe_*`（5 条）、`missing_tool`、`inferred_declaration`、`untyped_declaration`、`return_value_discarded`。
- `return_value_discarded` 暂不启用：存量主要是 `connect()` 等故意忽略的返回值，开启会逼出无意义变量或大量 `@warning_ignore`。
- 外部类 emit 的信号用 `@warning_ignore("unused_signal")` 标注；故意开火即忘的协程用 `@warning_ignore("missing_await")`。
- `debug/gdscript/warnings/directory_rules` 默认排除 `res://addons`，第三方代码不跟项目警告配置走。

编译检查：

- `tools/compile_check/check_scene.tscn` 以场景方式启动，autoload 已注册；遍历首方 `*.gd` 逐个 `load()`。
- 只认 `SCRIPT ERROR: Parse/Compile Error`、`Failed to load script`、`Failed to instantiate an autoload`；退出时的 RID/ObjectDB 泄漏警告不算失败。
- 运行前把 `APPDATA` / `XDG_DATA_HOME` 指到临时目录，不碰真实存档。
- 首次/无 `.godot` 缓存时先跑一次 `--import`（约 8 秒）；有缓存约 3 秒。

## 例外

`tools/lint/allowlist.toml`：

```toml
[[allow]]
rule = "commented-code"
path = "Scripts/example.gd"
reason = "保留旧实现对照，2027 年前删除"
expires = "2027-01-01"
```

- 四个字段缺一不可；`expires` 过期、条目没命中都会让检查失败。
- 例外是债务，不是消音器；到期就修，或续期并写清原因。

## 新增规则

1. 在 `tools/lint/rules.py` 加规则类，错误信息里写一句原因。
2. 在 `tools/lint/tests/test_rules.py` 加一正一反 fixture。
3. 先在项目上跑 `--all` 看基线：有存量就先清理或写 allowlist，再把级别提到 error。
4. 更新本页规则表和 `DOC/INDEX.md`（若改了路由）。

能改 API 让错误不可能发生的，优先改 API，不要为同一件事堆多条规则。规则预算先控制在 10 条以内。

## 边界

- 不检查 `addons/`、`.godot/`、`base_mods/`、`mods/`；`modkit/` 按规则单独豁免。
- 暂不引入 gdtoolkit/gdformat；格式统一另开一次提交。
- 规则误报时先改规则或删规则，不要让人习惯 `--no-verify`。
- CI：`.github/workflows/check.yml` 在 `windows-latest` 下载 Godot 4.7.2 后跑 `--all`；分支保护建议开启。
