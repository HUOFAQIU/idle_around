## 10. 扩展点

### 10.1 新增一颗魂灵

1. 主动魂灵：在 `game/content/Souls/<名字>/` 下新建 `SkillDefinition` 资源（`*_skill.tres`）：
   - `id`、`description`；
   - `effects`（`GameplayEffect`，伤害/治疗用 modifier 改 `health`）；只对自己生效的放 `self_effects`；
   - 伤害效果挂 `SoulDamageExecution`（`game/content/soul_damage_execution.gd`），填 `base_damage`；治疗、灼烧、剧毒、生命再生不要挂；
   - 护盾效果挂 `ShieldExecution`（`game/content/shield_execution.gd`），填 `base_shield`；
   - 需要从一个效果派生数值时参考 `RegenFromBurnExecution`（`game/content/regen_from_burn_execution.gd`，温泉再生 = 灼烧效果本次的结算值）；
   - `cooldown_seconds`（魂灵充能模型的冷却时长；不再使用 GAS 冷却效果）；
   - 普通战斗单位技能：`target_rule` 选 `TargetRule`；
   - 以魂灵为目标的技能：`target_rule` 选 `SoulTargetRule`，按需配 `haste_duration` / `slow_duration` / `freeze_duration` / `charge_duration`；
   - 可选 `crit_chance`、`crit_multiplier`、`projectile_scene`、`cast_time`；
   - 施法条件：`cast_require_all_tags`（必须全部持有）与 `cast_block_tags`（持有任意一个就拒绝），内部翻译成 `GameplayTagQuery`。
2. 新建魂灵资源（`*_soul.tres`）：
   - 主动魂灵用 `SoulData`，`skill` 指向上面的技能；
   - 被动魂灵用 `PassiveSoulData`（`game/content/passive_soul_data.gd`），`passive_effects` 填 `PassiveEffect`（`game/content/passive_effect.gd`，继承 `GameplayEffect` 的标记类），不填 `skill`；`PassiveEffect` 类型不写状态日志；
   - `types` 填语义类型（当前只有 `Soul.types.RealEstate`，供触发规则筛选）；`tags` 填见闻筛选标签（尺寸 `Soul.tags.Small/Medium/Large` 与效果标签 `Soul.tags.Damage` 等）；
   - 触发规则 `SoulData.triggers` 主动/被动魂灵通用，填 `PassiveTrigger`（`game/content/passive_trigger.gd`）：
     - `event_tag` 选 GAS GameplayEvent：`Event.Movement.UnitMoved`、`Event.Health.BelowPercent`、`Event.Combat.SoulUsed`、`Event.Combat.FreezeApplied`；
     - `target_scope` 选事件目标 / 自己 / 全体敌人；
     - `threshold_ratio` 只对 `Event.Health.BelowPercent` 生效；`once_per_battle` 控制一次性；
     - `required_soul_types` / `require_adjacent` 只对 `Event.Combat.SoulUsed` 生效；
     - `charge_source_seconds` 给来源主动魂灵充能；被动魂灵没有来源技能，忽略；
     - 新增事件：在 `godot_gas/tag_registry.tres` 注册 `Event.*`，在事件产生处 `asc.send_gameplay_event()`，不需要改 `SoulTriggerAbility`；
   - `equip_part` 选部位；
   - `item_name`、`type = "SOUL"`、`icon`、`columns/rows`；
   - 图鉴文案 `description`（可选；主动魂灵留空时窗口回退到 `skill.description`，被动魂灵建议填）；
   - 扫描线材质（`soul_scanline.gdshader`，`enable = 0`；被动魂灵不会打开它）。
3. 放进游戏：
   - 调试用：在 `inventory_window.gd` 加一个 `preload` + 按钮，`GBIS.add_item("inventory_0", soul)`；
   - 正式用：配置到某个怪物的 `soul_entries`，并给这颗魂灵单独配 `drop_chance`。
4. 见闻清单不需要手改：文件名以 `_soul.tres` 结尾时，YARD 的 `soul_registry` 扫描会自动登记。
5. 战斗内不需要改代码：主动魂灵由 `BattleUnit.add_soul_abilities()` 自动生成技能，显示名取 `item_name`；属性型被动由 `BattleWindow._spawn_player()` 收集 `passive_effects` 并在 `setup_from_scene()` 时挂到玩家 ASC；魂灵触发器由 `add_soul_abilities()` 统一登记，主动/被动魂灵走同一套绑定。

### 10.2 新增一种怪物

1. 在 `game/content/Monster/<名字>/` 下复制 `snake.tscn` 作为战斗场景，根节点保持 `team = ENEMY`；
2. 新建 `<名字>_data.tres`（`MonsterData`，`game/content/monster_data.gd`），配置：
   - `display_name`、`icon`、`description`、`max_health`；
   - `soul_entries`（携带的魂灵 + 各自的掉落几率；战斗时会生成对应技能，部位由魂灵自身 `equip_part` 决定，没配的部位就不存在）；
   - `battle_scene` 指向第 1 步的场景；
3. 配场景里的 ASC `attribute_sets`（可用 `MonsterStatsAttributeSet` 或新建）；根节点用 `CharacterBody2D` 并挂圆形 `CollisionShape2D`，移动速度配 `move_speed`、攻击范围配 `attack_range`，移动由 `BattleManager` 统一驱动。注意 `attack_range`（像素）要小于等于它攻击技能 `TargetRule.max_range` 换算后的像素值（格数 × `BattleManager.cell_size_px`），否则怪会停在技能够不着的距离空放；
4. 不需要改代码：文件名以 `_data.tres` 结尾时，YARD 的 `monster_registry` 会自动登记；`BattleWindow._spawn_enemy()` 从 `CollectionDB.pick_random_monster()` 随机取用。

### 10.3 新增技能（不改代码）

- 用现有 `TargetRule` 模式 + `GameplayEffect` + `projectile_scene` 就能组合出大部分主动技能；
- 新的战斗单位目标模式 → 扩展 `TargetRule.Mode` 和 `resolve()`；
- 新的魂灵目标模式 → 扩展 `SoulTargetRule.Mode` 和 `resolve()`；
- 新的效果类型（中毒等）→ 先用 GAS 的 `GameplayEffect`（周期效果、modifier）实现，再补标签和 Cue；护盾参考 `ShieldExecution`；
- 单位冻结 → 参考 `freeze_unit.tres`：`DURATION` + `State.Frozen` + 持久 Cue；魂灵级冻结 → 参考 `SkillDefinition.freeze_duration` + `ChargedAbility.apply_freeze()`；
- 新增持续伤害/再生 → 参考 `burn_tick.tres` + `BurnTickExecution` 或 `regen_tick.tres` + `RegenTickExecution`：周期效果只负责计时，每次 tick 用 execution 读取目标状态并返回属性变化；`effect_received` 在周期效果上只表示“已施加”，每跳叙事监听 `periodic_effect_ticked`；
- 新的“状态” → 先加到 `godot_gas/tag_registry.tres`，再用插件重新生成 `gameplay_tags.gd`。

### 10.4 新增窗口

1. 新建场景，根节点用 `Window`，挂一个 `extends BaseWindow` 的脚本；
2. 在场景里设 `open_position`（或在 `control.tscn` 实例上覆盖）；
3. 把场景实例加到 `Main/control.tscn`；
4. 在 `Main/control.gd` 里加按钮/信号并调用 `popup_window()`。

### 10.5 新增特效

按 `特效/effects.md` 的三步走：写 `GameplayCueNotify` 场景 → 登记到 `godot_gas/cue_registry.tres` → 挂到 `GameplayEffect` 的 `application/persistent/periodic/removal_cue_tags`。

UI 物品（例如魂灵格子）没有战场节点，不能直接挂 Cue；参考 `ItemView._apply_freeze_shader()`，用 `SoulData` 的状态字段驱动材质参数和 Kits 徽章。
