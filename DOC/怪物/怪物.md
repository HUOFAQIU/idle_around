怪物没有魂器，携带的魂灵按 `MonsterData.soul_entries` 的配置顺序生成一行虚拟魂灵栏，用来释放技能。
（实现状态：`SoulSlot.virtual_slots()` 按列表顺序排；魂灵已取消部位概念，怪物也不需要配置部位。）

# 数据来源
怪物名字、血量、攻击范围、移速、图鉴/战斗贴图都写在 `MonsterData`；战斗场景只保留碰撞体、节点和默认表现，刷怪时由 `BattleSession._spawn_enemy()` 注入。新增怪物时不要再把 `attack_range` / `move_speed` / 名字 / 贴图区域写进 `.tscn`。

# 掉落
怪物能掉落它所有的魂灵，掉落几率单独设定
击败怪物可以掉落，掉落直接进仓库窗口。

# 刷怪逻辑

- 刷什么怪、刷多少、什么时候刷完全由地图配置决定，见 `战斗/地图.md`。怪物本身不再配 `spawn_weight` / `is_rare`，也不存在全局随机刷怪池。
- 地图条目的 `monster_id` / `kill_monster_id` 指到这里的怪物 `content_id`；`MapCatalog` 会校验怪物存在。
- `BattleSession` 把地图条目产生的怪物 id 入队，再由 `BattleManager.spawn_one()` 消费；刷新距离仍由 `MonsterData.spawn_distances` 决定。
- 测试：`TestAPI.get_battle_state()` 快照里的 `map` / `map_kills` / `pending_spawns` 看地图刷怪进度；刷新距离用 `TestAPI.get_monster_spawn_distances(id)`。

# 刷新距离

- `MonsterData.spawn_distances`（`Array[int]`，单位格）决定这只怪可以刷在离角色几格；刷怪时把请求距离对应的六边形环格子合并后随机选一格，距离没有格子时退到最近的有格环。
- 默认 `[3]`；现有怪物不填资源就是 3 格。想让一只怪出现在不同距离，填 `[2, 3, 4]` 这类数组。
- 选怪在选格之前：`BattleSession` 先决定刷哪只怪，再按这只怪的 `spawn_distances` 选格；不同怪可以有不同距离。
- 开战时按玩家所在格缓存一次「距离 → 格子」表（`BattleGrid.cells_by_distance()`），复活重开会重建。
- 请求的距离在当前地图没有格子时，退到离请求距离最近的有格环；整张图都没有格子才放弃这次刷怪。
- `ModLoader` 校验数组非空且每个距离 `>= 1`。
