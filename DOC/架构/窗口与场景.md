## 3. 启动与窗口外壳

### 3.1 启动链

`Main/control.tscn` 的根节点是 `Control`，挂 `Main/control.gd`。

```
Control (control.gd)
├─ Setting (setting.gd)          → 启动时把主窗口贴到屏幕左下角
├─ StatusBarContainer            → 主窗口顶部状态栏（44px）
│  ├─ Button       "<"           → 主窗口移到左下角
│  ├─ Button2      "T"           → 切换置顶（always_on_top）
│  ├─ Button3/4/5  （空）        → 暂未接逻辑
│  └─ Button6      ">"           → 主窗口移到右下角
├─ GridContainer                 → 3×3 功能按钮
│  ├─ Button  人物  → CharacterWindow
│  ├─ Button2 魂灵  → EquipmentWindow
│  ├─ Button3 仓库  → InventoryWindow
│  ├─ Button4 商店  → ShopWindow
│  ├─ Button5 战！  → BattleWindow
│  ├─ Button6 图鉴  → CollectionWindow
│  ├─ Button7 调试  → DebugWindow
│  ├─ Button8      （空）        → 暂未接逻辑
│  └─ Button9      → ModWindow
├─ CharacterWindow
├─ EquipmentWindow
├─ InventoryWindow
├─ BattleWindow
├─ ShopWindow
├─ CollectionWindow
├─ TooltipWindow
├─ InfoWindow
├─ DebugWindow
├─ ModWindow
└─ ItemWindow
```

`control.gd::popup_window()` 的规则：

- 窗口已经可见 → `hide()`（再点一次就是关）；
- 是 `BaseWindow` → 调 `open_window()`，按 `open_position` 摆放，没配就居中；
- 不是 `BaseWindow` → `popup_centered()`。

存档读档时机：`SaveManager` 是 autoload，排在 `Warehouse` 之后；启动时等一帧，让 `Warehouse` 预注册 `inventory_0..inventory_9`、各窗口在 `InventoryView._ready()` 里注册 `cell_0..3`，再执行 `load_game()`。不要在 `Control._ready()` 之前读档，否则容器还不存在。详见 `架构/存档.md`。

mod 挂载时机：`ModLoader` 是第一个 autoload，在 `_init()` 里扫描/挂载，早于 `CollectionDB` 建立内容目录；详见 `架构/Mod系统.md`。

### 3.2 BaseWindow

`Windows/base_window.gd`：

- `@export var open_position: Vector2i`：任一坐标为负数表示“居中”；
- `open_window()`：有位置时 `popup(Rect2i(open_position, _popup_size()))`，尺寸取 `max(当前尺寸, 内容最小尺寸)`；
- `_ready()`：禁止缩放、最小化、最大化；
- `close_requested` → `hide()`。

场景细节：

- `TooltipWindow`：`borderless = true`、`always_on_top = true`、`unfocusable = true`、`mouse_passthrough = true`，`wrap_controls = true` 按内容自动伸缩，`min_size = 200×100`，默认隐藏。
- `ItemWindow`：`always_on_top = true`、`unfocusable = true`、`mouse_passthrough = true`，默认隐藏；在 `control.tscn` 的实例上额外覆盖了 `borderless = true`。
- `InfoWindow`：场景尺寸 600×400，默认隐藏。
- `CharacterWindow`：场景尺寸 300×300。
- `CollectionWindow`：场景尺寸 600×600，隐藏由 `control.tscn` 实例上的 `visible = false` 控制。
- `InventoryWindow`：场景尺寸 850×850。
- `BattleWindow`：场景尺寸 1000×1100。
- `DebugWindow`：场景尺寸 1200×760，可缩放；界面由脚本构建。

### 3.4 三个全局单例窗口

后加载的脚本通过静态变量拿单例，不依赖节点路径：

| 类 | 单例 | 关键接口 |
|---|---|---|
| `TooltipWindow` | `TooltipWindow.instance` | `show_tip(owner, layer, title, body := "")` / `hide_tip(owner)`；层级 `COORD < ITEM` |
| `InfoWindow` | `InfoWindow.instance` | `append_line()` / `clear_log()` / `toggle()` |
| `ItemWindow` | `ItemWindow.instance` | `hold(view, offset, base_size)` / `clear()` |

注意点：

- **TooltipWindow 的内容节点**：`Panel/Margin/VBox` 下是 `TitleLabel`（大字号标题行）和 `BodyLabel`（`RichTextLabel`，正文）。
  - 标题行显示魂灵名 / 物品名 / 战斗坐标；正文只有魂灵 tooltip 才有，由 `Windows/Tooltip/soul_tooltip.gd` 的 `SoulTooltip.build()` 生成，正文为空时隐藏 `BodyLabel`。
  - 正文开启 BBCode；`SoulTooltip.build(soul, true)` 按 `GameColors` 全局色板给灼烧 / 生命再生 / 剧毒 / 治疗 / 护盾 / 冻结 / 加速 / 减速 / 充能 / 伤害 / 暴击率上色，`[ 狼 ]` 这类方括号会转义成 `[lb]` / `[rb]`。
  - 窗口已改为 `borderless`，标题不再依赖原生标题栏，而是画在正文区的 `TitleLabel` 上，因此标题字号可以和正文分开调。
  - `show_tip(owner, layer, title, body := "")` / `hide_tip(owner)` 不是立即改 `visible`，而是记账到 `_process` 里统一结算，避免同一帧“先隐藏再显示”导致 OS 窗口闪烁；`body` 支持 BBCode。
  - `COORD` 是战斗窗口的格子坐标，`ITEM` 是物品/魂灵；低层级不能覆盖或隐藏仍然有效的高层级 owner。
  - `_place_near()` 默认在鼠标右下方，右边/下边放不下就翻边，再夹回屏幕内。
  - 标题、正文和位置只在值真的变化时才写。战斗窗口每个物理帧都会调 `show_tip`，鼠标停着时 `_place_tip` 也会每帧跑；文字没变就不改 Label、不 `reset_size()`，位置没变就不调 OS，避免布局重算和窗口管理器做无用功。
  - 当前用 `DisplayServer.screen_get_size()`，不是可用区域。
- **ItemWindow** 的 `_process` 每帧同步尺寸并跟随鼠标；`borderless` 让拖拽时的物品窗口没有标题栏。
- **InfoWindow** 的战斗日志来自 `BattleManager.log_sink`，由 `BattleWindow` 在开战时接上。

### 3.5 主窗口贴边

- `Scripts/setting.gd`：`_ready()` 根据 `DisplayServer.screen_get_usable_rect()` 把主窗口放到左下角。
- `Main/status_bar_container.gd`：`<` 左下角、`>` 右下角；`T` 切换 `always_on_top`，按下态在代码里覆盖成亮绿色。
- 偏移量都来自 `GameGlobal.WINDOWPOSOFFSET`（5px）。

## 8. 场景与配置

### 8.1 `Main/control.tscn`

- 根节点 `Control`，挂 `control.gd`；
- `Setting` 节点挂 `setting.gd`，启动时贴左下角；
- `StatusBarContainer`：`<`、`T`、三个空按钮、`>`；
- `GridContainer`：人物、魂灵、仓库、商店、战！、图鉴，以及三个空按钮；
- 9 个窗口实例，初始 `visible = false`（`CollectionWindow` 在场景里就是隐藏的，其余在 `control.tscn` 实例上隐藏）。
- 各窗口的打开位置见 3.3；`ItemWindow` 在 `control.tscn` 的实例上覆盖了 `borderless = true`。

### 8.2 `BattleWindow`

- 窗口 1000×1100；场景默认位置 (0,36)，实际打开时由 `control.tscn` 的 `open_position` 覆盖为 (240,165)；
- `Tile` 位置 (490,475)，`GroundTileMapLayer` 是六边形图块，图块尺寸 32×32；
- 单位统一挂在 `Tile/Units` 下，和地图同一个坐标系；
- `CanvasLayer/Control` 里是顶部按钮栏和左下角生命/状态条：
  - `PlayerHealthBar`（220×18，距左 70、距底 12），中间显示当前/最大生命值，左侧有“生命”标签；
  - `PlayerRegenBar` / `PlayerShieldBar` / `PlayerBurnBar` / `PlayerPoisonBar`（220×18，从生命条上方依次向上排列），分别显示生命再生、护盾、灼烧、剧毒；
  - 四条状态条都是满条显示，中间显示当前数值，左侧分别有“再生”“护盾”“灼烧”“剧毒”标签；数值为 0 时隐藏；
- `Units` 下不预先放任何单位，开战时由 `BattleWindow._spawn_player()` / `_spawn_enemy()` 实例化。

### 8.3 魂灵窗口

- 场景 320×420；
- 四个 `VBoxContainer`（`Cell0..Cell3`），每个高 96：
  - 上 32px 是部位标签（`HEADSOUL` / `TORSOSOUL` / `ARMSSOUL` / `LEGSSOUL`）；
  - 下 64px 是 `InventoryView`，10 列 × 2 行，`avilable_types = ["SOUL"]`，`equip_part` 对应部位。
