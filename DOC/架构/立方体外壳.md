## 1. 场景结构与层序

主场景 `Main/Cube/Scenes/main.tscn` 中，`CubeView`（CanvasLayer 1024）包裹 `SubViewportContainer` + `CubeViewport` 渲染 3D 立方体，兄弟节点为 `GameUI(1)`、`HUD(1024, 树中更靠后)`、`CubePlacement`、`WindowPassthrough`；上方还有 `DragLayer(1025)` 与 `TooltipLayer(1026)`。子树节点路径统一由 `Main/Cube/Scripts/cube_scene_paths.gd::CubeScenePaths.resolve()` 解析。

- **六面装配**：共用 `face_3d.tscn`（`content_scene` + `viewport_size`）。01 存档位、02 主菜单（`PetPanel`）、04 角色选择、05 地图板均为 300×300；03/06 保留 512×512 `FaceUI` 演示面。启动朝向 `(0,0,0)` 正对 01 面，松手 25° 阈值回正，流程翻面走 `CubeRig.flip_to_face()`（复用 `State.ALIGNING` slerp，`snap_face_to_camera()` 供测试瞬移）。
- **`FaceContent` 与水印**：所有面内容继承 `FaceContent`（约定 `identify_requested`、`setup()`、`content_id()`），基类在 `backdrop_path` 后自动插入 `%02d` 面号水印（alpha 0.16，高 55%）。立方体主题 `cube_theme.tres` 仅挂在面内容/HUD 根，不污染全局 UI 主题。

## 2. 面尺寸与屏幕锚定（`CubePlacement`）

| 项 | 值 |
|---|---|
| 面片 QuadMesh / 碰撞盒 | 1.9 × 1.9（留 0.05 边距供拖转） / 2 × 2 |
| 子视口 / 屏幕投影 | 01/02/04/05 为 300×300（投影 1:1 约 300px）；03/06 为 512×512 |
| 锚定与持久化 | 默认主视口中心；拖动圆点仅改内存坐标，重启回中 |

- **缩放公式**：按视口高度与相机 FOV(12°) 带面片深度项反解 `k * depth / (FACE_WORLD_SIZE + FACE_OFFSET * k)`（`FACE_OFFSET = 1.005`），场景中 Cube 保持单位缩放，运行期由 `CubePlacement` 每帧覆盖；调大小改 `TARGET_FACE_PX`。
- **布局稳定**：全屏/DPI 切换后等一帧 `process_frame` 再重算默认中心或夹取；子视口尺寸 `<2px` 时跳过 `_apply()`。

## 3. 输入链路与锁定拦截

1. **主视口拾取**：`CubeInputSurface`（Layer 1024）仅在立方体投影凸包或拖动圆点内命中，命中后 `push_input` 给 `CubeViewport` 并 `accept_event()`（压住的面板不收 hover/点击）；按住拖出轮廓靠 GUI `mouse_focus` 保持。
2. **`CubeRig` 分流**：左键先测拖动圆点（若圆点被夹到边缘盖住 02 面，仍先做射线让 `ui_capture` 控件优先）；命中 `ui_capture = true` 面且 `Face3D.ui_hit_at()`（基于 `gui_get_hovered_control()`）查到可交互控件时进入 `_ui_face` 捕获而不旋转，其余区域拖动 >7px 取消按钮并旋转。右键/滚轮命中 `ui_capture` 面直接复制转发。
3. **释放兜底与清理**：`CubeRig._process` 每帧核查左键是否仍按下以防 release 被主视口吃掉；离开面时先向子视口推屏幕外 motion 再 `notify_mouse_exited()` 才能清净 hover/Tooltip；窗口失焦或指针离开由 `InputSurface` 转发给 `CubeRig.pointer_left()`。
4. **锁定面**：`Face3D.set_locked(true)` 拦截全部面内容输入并显示 `LockOverlay`（实例化内容后必须 `move_child` 到最上层），空白处仍可旋转立方体。

## 4. 透明窗口点击穿透与 Godot 4.7 全屏坑

- **区域计算**：`WindowPassthrough` 将立方体包围盒 8 角（`CubeProjection.HALF_EXTENT = 1.03`）投影成凸包（外扩 28px），与可见面板、Tooltip、ItemWindow、HUD Toast、拖动圆点矩形（外扩 8px）经 `Scripts/ui/ui_region.gd` 用 2px 走廊合并为单多边形写入 `Window.mouse_passthrough_polygon`；按住鼠标或旋转期间临时扩为全客户区（空数组表示取消穿透而非全透）。
- **DWM 延迟收缩（关键坑）**：Windows 下 `mouse_passthrough_polygon` 底层是 `SetWindowRgn`，收缩早于画面提交会导致关窗后残留一帧面板背景。区域**完全包含于旧区域**的收缩必须延迟 `SHRINK_HOLD_FRAMES = 3` 帧应用，扩张与旋转立即生效。
- **Godot 4.7 全屏透明坑**：
  - `project.godot` 必须保持 `mode=3`、`borderless=true`、`transparent=true`、`per_pixel_transparency/allowed=true`、`viewport/transparent_background=true`、`stretch/mode="disabled"`；**不可**同时启用 `resizable=false`、`maximize_disabled=true`、`always_on_top=true`，否则 `mode=3` 降级且透明失效。
  - **禁止运行期改主窗口 `position`/`size`**（Windows 下破坏逐像素透明）；不可用 `WINDOW_FLAG_MOUSE_PASSTHROUGH` 替代多边形（Windows 仅传给同应用窗口）；编辑器运行前关闭 Embed Game。

## 5. 渲染、扩展与已知限制

- **渲染**：Forward Plus / D3D12，`CubeViewport` 设 `transparent_bg=true`、`own_world_3d=true`、`msaa_3d=2`、`UPDATE_ALWAYS`，`fov=12°`（改 FOV 需同步核对 `FloatingMotion`），3D 射线走 Godot 默认物理。
- **扩展**：新面继承 `FaceContent` 在 `face_3d.tscn` 实例指定 `content_scene`；新主菜单按钮挂 `PanelMenuButton` 并在 `Main/control.gd::_panels` 登记；手感调 `cube_orientation.gd` 常量。
- **限制**：立方体压住的面板不可点且不弹 Tooltip；拖到屏幕边缘有轻微透视；`CubeRig` 当前未转发键盘事件。
