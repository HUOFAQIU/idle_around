# 魂灵
刷的就是这
目前角色身上 4 个部位可以装备魂灵。
魂灵分小（占 1 格）中（占 2 格）大（占 3 格），每个部位均有 10 格，共计 40 格。
目前来说，魂灵就是游戏的全部，技能、属性都是由魂灵提供的。

### 主动技能、被动技能
刷什么？roll
1、冷却
```
cooldown
固定游戏为 60 帧，每帧充能为 1/60，1 秒充能 1 秒当前冷却
加速时，在加速时间内，每帧充能为 2/60，1 秒充能 2 秒当前冷却
减速时，在减速时间内，每帧充能为 1/120，1 秒充能 0.5 秒当前冷却
同时被加速减速时，相互抵消，不受影响，每帧充能为 1/60，1 秒充能 1 秒当前冷却
被充能时，获得被充能数值秒当前冷却

当当前冷却等于主动技能冷却时，释放技能
当被充能数值大于剩余冷却时，直接释放技能，被充能数值不会影响下次冷却
```

2、数值区间
```
伤害Damage，可以暴击，暂时不想区分伤害类型

治疗Heal，可以暴击，恢复生命，净化治疗量 5% 的自身剧毒和灼烧

再生Regen，可以暴击，每 1 秒恢复再生数值生命；与剧毒直接相减，数值大的一方生效

护盾Shield，可以暴击，优先承伤

灼烧Burn，可以暴击，0.5 秒结算一次伤害，减少 3% 当前灼烧层数，对护盾造成伤害减半

剧毒Poison，可以暴击，1 秒结算一次，无视护盾；与再生直接相减，数值大的一方生效

冻结Freeze ，冷却停止，可以被充能，buff、debuff照常执行

充能Charge，当前冷却减少

减速Slow，冷却充能减半

加速Haste，冷却充能翻倍
```
