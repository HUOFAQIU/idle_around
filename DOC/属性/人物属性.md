# 人物属性

> 类型：设计 | 状态：设计 | 整理：2026-11-15
> 何时读：确认人物属性池
> 关键词：属性 生命 max_health health player_stats_attribute_set
> 代码：`godot_gas/attributes/player_stats_attribute_set.gd`
> 相关：`架构/GAS.md`

当前设定上的属性不多，文件是 `godot_gas/attributes/player_stats_attribute_set.gd`。

| 属性 | 说明 |
|---|---|
| `max_health` | 最大生命值；`health` 的上限 |
| `health` | 当前生命值，钳制在 `[0, max_health]` |
| `damage_bonus` | 己方魂灵直接伤害加成（固定值，默认 0） |
| `burn` | 当前灼烧层数；每 0.5 秒按整数层数结算并衰减 3% |
| `shield` | 当前护盾值；优先承伤，无上限、无持续时间 |
| `poison` | 当前剧毒值；每秒与生命再生相减后按净值结算，无视护盾 |
| `regen` | 当前生命再生值；每秒与剧毒相减后按净值恢复生命 |

怪物使用 `monster_stats_attribute_set.gd`，属性相同，没有 `damage_bonus`。

所有属性落地值均为整数：计算过程（暴击、比例、百分比加成）允许小数，写入属性前统一向下取整；`max_health` 的百分比加成也按最终值取整。兜底位置是两个属性集的 `pre_attribute_change()`，语义取整在执行器/`DamageResolver` 里完成。
