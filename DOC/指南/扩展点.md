## 1. 新增魂灵（主动 / 被动）

1. **主动技能**（`base_mods/core/souls/<name>/*_skill.tres`）：配 `SkillDefinition`（`id` 留空由 `ModLoader` 派生；配 `cooldown_seconds`、`cast_times`、`crit_*`、`self_effects` 与 `steps`）。`UnitSkillStep` 配 `TargetRule` + `effects`/`projectile_scene`（可选 `status_magnitude`、`effect_duration`、`hit_cue_tag` 复用共享效果资源）；`SoulSkillStep` 配 `SoulTargetRule` + 状态时长。直伤挂 `SoulDamageExecution`，护盾挂 `ShieldExecution`。
2. **魂灵资源**（`*_soul.tres`）：主动用 `SoulData`（挂 `skill`），被动用 `PassiveSoulData`（挂 `PassiveEffect`，留空 `skill`）。填 `types`（`Soul.types.*`）与 `tags`（**必须恰好 1 个尺寸标签** `Small/Medium/Large` + 效果标签），中文名补进 `Scripts/soul_text.gd`；触发器配 `SoulData.triggers`（`PassiveTrigger`，`event_tag` 需 `Event.*`）；文案写纯文本占位符进 `tooltip_blocks`；图标与占格对齐尺寸并挂 `soul_scanline.gdshader`（`enable=0`）。
3. **登记与投放**：在 `base_mods/core/mod.json` 的 `content.souls` 登记（`<name>_soul`）；正式投放配进怪物 `soul_entries`，调试用见闻右键或 `TestAPI.add_soul()`。

## 2. 新增怪物、地图与魂器

- **怪物**：在 `base_mods/core/monsters/<name>/` 放自包含的 3D 网格 `*.res`（`ArrayMesh`，顶点色/贴图都烘进网格，不引用外部场景与贴图）；新建 `MonsterData`（配 `display_name`/`icon`/`max_health`/`attack_range`/`move_speed`/`spawn_distances`/`soul_entries`，3D 表现配 `mesh_3d`/`visual_scale`/`hit_height`/`debris_color`）；`ModLoader` 要求 `mesh_3d` 与旧 `battle_scene` 至少配一个；登记到 `base_mods/core/mod.json` 的 `content.monsters`。战斗用 `game/battle/map_run.gd` 按地图条目刷怪。
- **地图**：暂硬编码在 `game/content/map_catalog.gd`。在 `base_mods/core/maps/<name>/` 建 `MapData`（`content_id`/`rarity`/`spawn_entries`），登记进 `MapCatalog` 与 `get_map_ids()`，用 `TestAPI.validate_maps()` 校验。
- **魂器**：在 `base_mods/core/vessels/<name>/` 建 `SoulVesselData`（`category="VESSEL"`、`vessel_kind`、占格与内部容器尺寸、`SoulVesselEffect`），登记到 `base_mods/core/mod.json` 的 `content.vessels`；新增效果类型需同步 `SoulVesselEffect.Stat` 与 `SoulRuntime`。

## 3. 新增技能机制与特效

- **新机制**：优先组合现有 `TargetRule`/`SoulTargetRule` + `GameplayEffect` + `steps`；新目标模式扩对应 `Mode`/`resolve()`，新步骤域继承 `SkillStep` 并补 `ModLoader` 校验；新周期状态继承 `PeriodicStatusTickExecution`；新状态标签先写入 `godot_gas/tag_registry.tres` 再生成 `gameplay_tags.gd`。
- **新特效（Cue）**：按 `指南/特效与Cue.md` 建 `GameplayCueNotify` 场景 → 登记 `content.cues` → 挂到 `GameplayEffect` 的 `*_cue_tags`。UI 物品（魂灵格）不挂 Cue，改走 `ItemView` 材质与 Kits 徽章。

## 4. 新增窗口、角色与立方体面内容

- **窗口**：根节点 `Control` 挂 `extends BaseWindow`，初始子节点在 `_ready()` 同步挂根（动态节点挂 `TitleUI/ContentRoot`），配 `open_position`；作为直接子节点放进 `Main/control.tscn`，在 `Main/control.gd::_panels` 登记 id，并在 `Main/pet_panel.tscn` 加 `PanelMenuButton`。
- **可选角色**：在 `game/content/Characters/characters/` 建 `CharacterDefinition`（指向 `PlayerProfile`），登记进 `CharacterCatalog.all()`；业务逻辑统一读 `GameFlow.get_player_profile()`。
- **立方体面内容**：继承 `FaceContent`（点击优先设 `ui_capture=true`），在 `cube.tscn` 对应 `face_3d.tscn` 实例设 `content_scene` 与 `viewport_size`，信号由 `main.gd` 接线，锁定归 `GameFlow`。
