# 代码工作方式与边界

- 分级读取：≤80 行的短文档/脚本直接一次读完省轮次；>120 行的大文件先 Grep 定位标题或符号，再按 `offset/limit` 读命中段；同会话已读文件不重复整读。
- 同一文件先读完、规划好再一次性改完；独立工具调用并行执行。
- 超过 200 行的命令输出先落盘，再用 `grep`/`tail` 取关键行；跨 3 个以上文件的搜索派 Explore，只回结论和 `file:line`。
- 按系统能自然容纳的方式落地；找不到自然落点、需要先重构时停下等确认（`docs/架构/边界与seam.md`）。
- `addons/` 默认只读：改动前先说明并等确认。
