# 数据来源
怪物名字、血量、攻击范围、移速、图鉴/战斗贴图都写在 `MonsterData`；战斗场景只保留碰撞体、节点和默认表现，刷怪时由 `BattleSession._spawn_enemy()` 注入。新增怪物时不要再把 `attack_range` / `move_speed` / 名字 / 贴图区域写进 `.tscn`。

# 掉落
怪物能掉落它所有的魂灵，掉落几率单独设定
击败怪物可以掉落，掉落直接进仓库窗口。

# 刷怪逻辑

- 常规刷怪池由 `MonsterData.spawn_weight` 和 `is_rare` 共同决定：权重 `0` 或 `is_rare = true` 的怪都不参与随机刷怪。蝮目前 `spawn_weight = 0`、`is_rare = true`，常规池只有蛇。`ModLoader` 会校验 `is_rare = true` 时 `spawn_weight` 必须为 0。
- 每死亡 10 只常规怪（`spawn_weight > 0` 且非稀有），下一只刷怪改为刷 1 只 `is_rare = true` 的怪（当前是蝮）；计数余数保留（连续击杀 20 只会排队 2 只），开战/关窗/重开清零。
- 实现：`BattleSession._on_enemy_died()` 计数、`_pick_monster_for_spawn()` 选怪，稀有怪由 `CollectionDB.pick_rare_monster()` 从 `is_rare` 条目里随机挑；每秒刷怪心跳由 `EnemySpawner` 驱动，`BattleManager.spawn_one()` 保留为门面。
- 测试：`TestAPI.get_battle_state()` 快照里的 `normal_kills` / `pending_rare_spawns` 可直接看规则进度；稀有怪清单用 `TestAPI.get_rare_monster_ids()`；刷新距离用 `TestAPI.get_monster_spawn_distances(id)`。

# 刷新距离

- `MonsterData.spawn_distances`（`Array[int]`，单位格）决定这只怪可以刷在离角色几格；刷怪时把请求距离对应的六边形环格子合并后随机选一格，距离没有格子时退到最近的有格环。
- 默认 `[3]`；现有怪物不填资源就是 3 格。想让一只怪出现在不同距离，填 `[2, 3, 4]` 这类数组。
- 选怪在选格之前：`BattleSession` 先决定刷哪只怪，再按这只怪的 `spawn_distances` 选格；不同怪可以有不同距离。
- 开战时按玩家所在格缓存一次「距离 → 格子」表（`BattleGrid.cells_by_distance()`），复活重开会重建。
- 请求的距离在当前地图没有格子时，退到离请求距离最近的有格环；整张图都没有格子才放弃这次刷怪。
- `ModLoader` 校验数组非空且每个距离 `>= 1`。
