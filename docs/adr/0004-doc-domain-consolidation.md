# ADR 0004：文档收敛为五正交域并由脚本自动扫描元数据

> 类型：记录 | 状态：有效 | 核对：2026-11-24
> 何时读：新增文档不知该放哪个目录、调整文档校验逻辑或评估 INDEX.md 体积时
> 关键词：ADR 文档 5域 正交目录 自动扫描 index_meta Token优化
> 代码：`tools/lint/index_meta.py`
> 相关：`INDEX.md`、`指南/文档规范.md`、`adr/0002-pointer-docs.md`

**决策状态**：已接受 · 2026-11-24

## 背景

`docs/` 曾按“文档类型”与“业务实体”混用拆出 11 个顶层目录，其中 7 个目录仅含 1～2 篇文件，窗口文档散落在三个目录；同时 `docs/INDEX.md` 耦合了路由表、43 行手工文档清单与写作规范（体积 14.7 KB），3 天内被整读 18 次，成为高频 Token 消耗源，且手工清单无法发现漏登记的新文档。

## 决策

1. **目录收敛为五个正交域**：`架构/`（代码实现真相，吸收原 `窗口/` 2 篇实现文档）、`设计/`（玩法规则，收拢原 `魂灵/`、`战斗/`、`怪物/`、`属性/`）、`指南/`（操作、扩展与排障，吸收原 `特效/effects.md` 与 `架构/扩展点.md`）、`spec/`（短期变更契约）、`adr/`（长期架构决策）。
2. **`INDEX.md` 只保留精简路由表**：移除手工文档清单，文档头与写作规范迁入 `指南/文档规范.md`。
3. **`index_meta.py` 改为全量自动扫描**：自动校验 `docs/**/*.md` 文档头与日期格式，并验证 `INDEX.md` 路由表中引用的每个相对路径真实存在，不再维护手工清单行（局部更新 ADR 0002 的清单同步细则）。

## 后果

- 好处：`INDEX.md` 体积降至约 5 KB 以下；新增/修改文档免去手工维护清单与日期同步 diff；漏写文档头的新文件会被直接拦住。
- 代价：迁移阶段需要一次性更新技能与文档中的旧路径指针。
- 约束：不再为单个概念新建顶层目录；单篇文档保持在 200 行 / 10 KB 以内。

## 替代方案

- 把清单迁至独立 `docs/MANIFEST.md` 继续手工维护：虽然减小了 `INDEX.md`，但仍保留每次改日期的 git 噪音，且仍会漏检未登记新文档。
- 维持 11 个顶层目录只做文字精简：无法解决目录分类摇摆和碎片化查找成本。
