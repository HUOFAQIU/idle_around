> 实现：`架构/战斗数据与魂灵.md`、`窗口/见闻.md`

怪物同角色一样，都有数个装备部位，用来放置魂灵，释放技能
每个怪物的装备部位应该是可以配置的
比如现有的蛇有 headsoul 和 torsosoul 部位
headsoul，有`毒牙`这个魂灵
```
毒牙，res://Assets/souls/duya.png
小型，headsoul
3秒，造成 5 伤害。造成剧毒，等量于此魂灵伤害的 10%
```
torsosoul，有`滑溜身`这个魂灵
```
滑溜身，res://Assets/souls/hualiushen.png
中型，torsosoul
4秒，加速自身任意魂灵 2 秒
（这个任意是指不受位置限制，不受部位限制）
```
蛇并没有armssoul和legssoul，一定要注意

# 掉落
怪物能掉落它所有的魂灵，掉落几率单独设定
击败怪物可以掉落，掉落直接进仓库窗口。
