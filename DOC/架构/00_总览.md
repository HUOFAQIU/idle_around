## 1. 运行基线与单一真相

| 项 | 约定 / 真相来源 |
|---|---|
| 引擎与渲染 | Godot 4.7（Forward Plus / Windows D3D12，MSAA 4×，`run/max_fps=60`），详细配置以 `project.godot` 为准 |
| 主场景与窗口 | `Main/Cube/Scenes/main.tscn`（单 OS 透明窗口，基准 1600×960；`Main/control.tscn` 为主视口 GameUI 覆盖层，01/02/04/05 立方体面各 300×300，面板均为不透明 `BaseWindow`） |
| Autoload 清单 | **以 `project.godot` `[autoload]` 与 `tools/lint/boundaries.toml` 为单一真相**（`boundaries.py` 自动校验漂移）。硬性顺序约束：`ModLoader` 必须早于 `CollectionDB`；`GBIS` 全局名不可改；`SaveManager` 启动不自动读档 |
| 输入动作 | `inv_click` / `inv_use` / `inv_quick_move` / `inv_quick_sell` / `inv_split` 均为 `project.godot` 配置的鼠标事件（非键盘按键） |
| 插件划分 | 第三方放 `addons/`（GodotGAS、script-ide，默认只读）；项目自用放 `EngineTools/`（kanban_tasks、color_catalog、modkit） |

## 2. 目录职责与分层约束

| 目录 | 职责 |
|---|---|
| `Main/` | 3D 立方体外壳（`Cube/`）、主入口 `control.gd`、`PanelManager`、`PetPanel`、状态栏 |
| `Scripts/` | 全局服务与 Autoload（`mod/`、`save/`、`ui/`、`debug/`、`terminal/`、`commands/`、`test_api/`） |
| `Windows/` | 所有 `BaseWindow` 面板与浮层（`Battle/` 含 3D 战斗舞台与 HUD、`Info/`、`Inventory/`、`Vessel/`、`Character/`、`Tooltip/`、`Debug/` 等） |
| `game/` | 领域层：`battle/`（魂灵/GAS 战斗核心）、`flow/`（`GameFlow` 会话状态机）、`content/`（纯数据定义与 `WeatherPreset`）、`inventory/`（GBIS） |
| `base_mods/core/` | 内置官方内容（唯一清单为 `base_mods/core/mod.json`）；示例第三方 mod 在 `mods/` |
| `godot_gas/` / `Assets/` / `DOC/` | GAS 属性集与标签注册 / 通用贴图与扫描线 shader / 文档（唯一入口 `DOC/INDEX.md`） |

**硬性分层约束**（由 `tools/lint/boundaries.toml` 强制检查）：
- `game/battle/` 只读 `game/content/`，反向禁止；新增官方资源在 `base_mods/core/` 并同步 `mod.json`。
- `game/flow/` 只管会话状态与切档流程，磁盘持久化归 `Scripts/save/`；`addons/` 非必要不改，改动前先说明。
