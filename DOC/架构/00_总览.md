## 1. 项目概览

| 项 | 值 |
|---|---|
| 引擎 | Godot 4.7（Forward Plus） |
| 主场景 | `Main/control.tscn` |
| 帧率 | `run/max_fps=60`；物理帧默认 60 Hz，充能按 `1/120` 秒的整数刻度累加（60 Hz 下每帧 2 刻度） |
| 主窗口 | 300×300，不可缩放、不可最大化，`embed_subwindows=false`（每个 `Window` 都是独立系统窗口） |
| 编辑器插件 | GodotGAS、kanban_tasks、script-ide、YARD（Yet Another Resource Database） |

### Autoload

| 名称 | 脚本 | 作用 |
|---|---|---|
| `GameGlobal` | `Scripts/GameGlobal.gd` | 全局常量，目前只有窗口贴边偏移 `WINDOWPOSOFFSET = 5` |
| `GBIS` | `Windows/Inventory/grid_base_inventory_system/core/grid_base_inventory_system.gd` | 背包/仓库/商店系统入口；框架要求全局名必须是 `GBIS` |
| `GameplayCueManager` | `addons/GodotGAS/managers/gameplay_cue_manager.gd` | GAS 特效（Cue）管理器 |
| `CollectionDB` | `Scripts/collection_db.gd` | 见闻图鉴：YARD registry 索引、已遇见状态 |
| `CombatTelemetry` | `Scripts/debug/combat_telemetry.gd` | 战斗调试事件总线：环形缓冲、trace、JSONL 导出 |
| `SoulRuntimeDB` | `game/battle/soul_runtime_db.gd` | 玩家已装备魂灵的运行期注册表：SoulData 实例 → SoulRuntime |
| `SaveManager` | `Scripts/save/save_manager.gd` | 单槽存档：容器/见闻读写、自动存读档、备份与迁移 |

### 输入动作

| 动作 | 默认绑定 | 用途 |
|---|---|---|
| `inv_click` | 鼠标左键 | 拿起/放下物品、点击格子 |
| `inv_use` | 鼠标右键 | 使用物品 / 脱下装备（框架内置） |
| `inv_quick_move` | Shift + 鼠标左键 | 在打开着的背包之间快速移动 |
| `inv_split` | 鼠标中键 | 分割可堆叠物品 |

这些是在 `project.godot` 里配置的鼠标事件，不是键盘按键。

## 2. 目录总览

```
res://
├─ Main/                    主界面、状态栏、所有窗口的挂载点
├─ Scripts/                 GameGlobal / CollectionDB / CombatTelemetry / SaveManager（autoload）、setting（主窗口启动贴边）
│  ├─ save/                 存档管理 SaveManager、物品/容器编码 SaveCodec
│  └─ debug/                CombatTelemetry / CombatTrace / CombatSnapshot / SoulEffectContext
├─ Windows/                 所有独立窗口
│  ├─ Battle/               战斗窗口、地图、角色血条
│  ├─ Character/            人物窗口（空壳）
│  ├─ Equipment/            魂灵窗口（4 个部位容器）
│  ├─ Inventory/            仓库窗口 + GBIS 背包框架
│  ├─ Info/                 战斗信息窗口
│  ├─ Item/                 拖拽中的物品窗口
│  ├─ Shop/                 商店窗口（空壳）
│  ├─ Tooltip/              全局提示窗口
│  ├─ Collection/           见闻窗口（怪物/魂灵图鉴）
│  ├─ Debug/                调试窗口与魂灵状态行
│  ├─ base_window.gd        BaseWindow 基类
│  └─ Inventory/grid_base_inventory_system/   第三方网格背包框架
├─ game/
│  ├─ battle/               战斗运行时：单位、大脑、技能、寻路、投射物、血条、飘字、魂灵运行时
│  └─ content/              战斗内容数据：玩家/怪物场景、魂灵、技能、效果、掉落
│     ├─ Collection/        见闻的 YARD registry（魂灵 / 怪物清单）
│     └─ Kits/              魂灵状态徽章场景（加速/减速/冻结）
├─ godot_gas/               项目自己的 GAS 扩展：属性集、标签注册、Cue 注册
├─ Assets/                  贴图、六边形图块、扫描线 shader
├─ DOC/                     设计文档（过期内容在 DOC/archive/）
├─ Archive/                 不再引用的资源归档（`.gdignore`，Godot 不导入）
└─ addons/                  第三方插件（GodotGAS、kanban_tasks、script-ide、yard）
```

### 各目录职责

| 目录 | 职责 | 备注 |
|---|---|---|
| `Main/` | 主界面入口、状态栏、窗口实例 | `control.gd` 负责开关窗口 |
| `Scripts/` | 全局常量、主窗口初始位置、见闻图鉴服务、存档 | `setting.gd` 挂在主场景的 `Setting` 节点上；`collection_db.gd`、`save/save_manager.gd` 是 Autoload |
| `Windows/` | 游戏 UI 与窗口交互 | 除 `BaseWindow` 外，`TooltipWindow` / `ItemWindow` 直接继承 `Window` |
| `game/battle/` | 战斗逻辑，不依赖具体地图节点 | 只借 `TileMapLayer` 做格子→像素换算 |
| `game/content/` | 纯数据与场景配置 | 加魂灵/怪主要改这里 |
| `godot_gas/` | 项目侧 GAS 数据 | 标签注册表、属性集、Cue 注册表 |
| `addons/` | 第三方插件 | 非必要不修改；需要改时先说明 |
| `DOC/` | 设计文档 | 见 `DOC/INDEX.md` |
