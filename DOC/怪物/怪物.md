每个怪物的装备部位应该是可以配置的

# 数据来源
怪物名字、血量、攻击范围、移速、图鉴/战斗贴图都写在 `MonsterData`；战斗场景只保留碰撞体、节点和默认表现，刷怪时由 `BattleWindow._spawn_enemy()` 注入。新增怪物时不要再把 `attack_range` / `move_speed` / 名字 / 贴图区域写进 `.tscn`。

# 掉落
怪物能掉落它所有的魂灵，掉落几率单独设定
击败怪物可以掉落，掉落直接进仓库窗口。

# 刷怪逻辑

- 常规刷怪池由 `MonsterData.spawn_weight` 和 `is_rare` 共同决定：权重 `0` 或 `is_rare = true` 的怪都不参与随机刷怪。蝮目前 `spawn_weight = 0`、`is_rare = true`，常规池只有蛇。`ModLoader` 会校验 `is_rare = true` 时 `spawn_weight` 必须为 0。
- 每死亡 10 只常规怪（`spawn_weight > 0` 且非稀有），下一只刷怪改为刷 1 只 `is_rare = true` 的怪（当前是蝮）；计数余数保留（连续击杀 20 只会排队 2 只），开战/关窗/重开清零。
- 实现：`BattleWindow._on_enemy_died()` 计数、`_pick_monster_for_spawn()` 选怪，稀有怪由 `CollectionDB.pick_rare_monster()` 从 `is_rare` 条目里随机挑；每秒刷怪心跳由 `EnemySpawner` 驱动，`BattleManager.spawn_one()` 保留为门面。
- 测试：`TestAPI.get_battle_state()` 快照里的 `normal_kills` / `pending_rare_spawns` 可直接看规则进度；稀有怪清单用 `TestAPI.get_rare_monster_ids()`。
