## 1. 玩家与怪物属性池

玩家属性集在 `godot_gas/attributes/player_stats_attribute_set.gd`，怪物属性集在 `monster_stats_attribute_set.gd`（结构相同，但无 `damage_bonus`）。所有属性落地值均为整数，取整口径与结算公式见 `架构/战斗运行时_伤害与流程.md` §1。

| 属性 | 说明 |
|---|---|
| `max_health` | 最大生命值；`health` 的上限 |
| `health` | 当前生命值，钳制在 `[0, max_health]` |
| `damage_bonus` | 玩家专属：己方魂灵直接伤害固定加成（默认 0） |
| `shield` | 当前护盾值；优先承伤，无上限、无持续时间 |
| `burn` | 当前灼烧层数；每 0.5 秒按整数层数结算并衰减 3%，对护盾伤害减半 |
| `poison` | 当前剧毒值；每秒与 `regen` 按净值差结算，无视护盾 |
| `regen` | 当前生命再生值；每秒与 `poison` 按净值差恢复生命，永久叠加不衰减 |

## 2. 怪物数据、虚拟魂灵栏与掉落

- **数据集中**：怪物名字、血量、攻击范围、移速、图鉴/战斗贴图与 `battle_scene` 全部配在 `MonsterData`（`base_mods/core/monsters/`），刷怪时由 `BattleSession._spawn_enemy()` 注入，不在 `.tscn` 中写死数值。
- **虚拟魂灵栏**：怪物没有魂器，携带魂灵按 `MonsterData.soul_entries` 配置顺序经 `SoulSlot.virtual_slots()` 生成一行虚拟魂灵栏自动施法。
- **掉落**：怪物可掉落其配置的全部魂灵，各条目独立配概率，击败后直接进仓库。
- **刷怪来源**：已移除全局随机刷怪池与 `spawn_weight` / `is_rare`，刷什么怪完全由地图 `MapData.spawn_entries` 驱动（见 `设计/地图与战斗.md`）。

## 3. 刷新距离（`spawn_distances`）

- `MonsterData.spawn_distances`（`Array[int]`，单位格，默认 `[3]`）指定怪物可刷在距角色几格的六边形环；`ModLoader` 校验数组非空且每项 `>= 1`。
- 刷怪顺序为先由 `BattleSession` 决定怪物 ID，再合并该怪 `spawn_distances` 对应的六边形环随机选格；请求距离无格时回退到最近有格环，整图无格则放弃本次刷怪。
- 开战时按玩家格缓存「距离 → 格子」表（`BattleGrid.cells_by_distance()`），复活重开时重建。
