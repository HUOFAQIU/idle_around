本文是新增怪物及其配套魂灵的端到端执行顺序与门禁；各资源的字段清单与扩展细节见 `指南/扩展点.md`，不在此重复。

## 阶段 1：一页纸原型卡片（先定调，不动文件）

开始建资源前先对齐 5 项，避免中途返工：

| 项目 | 需敲定的内容 |
|---|---|
| 生态与波次 | 归属地图、定位（杂兵 / 精英 / Boss）、在场上的节奏角色（冲脸 / 辅助 / 拖节奏等） |
| 视觉与动画族 | 38° 俯视像素滤镜下的一眼轮廓 + 与绿草地拉开对比的主色块；复用 `lit_unit.gdshader` 哪套 `CUSTOM0.w` 骨骼族（`1~5` 人形 / `11~13` 四足 / `20` 弹跳 / `31~33` 飞行 / `41~43` 节肢 / `50` 蛇形） |
| 专属魂灵（1~3 个） | 怪物与玩家共用魂灵体系：定好尺寸、标签、冷却、情绪随机区间、是否复用现有 `SkillStep` / `GameplayEffect` |
| 空间与数值基线 | `max_health`、`move_speed`、`attack_range`、`body_radius`（占位半径）与 `visual_scale`、`hit_height` 的比例 |
| 表现与音效 | 受击/命中是否需要新 3D Cue、投射物或击杀碎块颜色 `debris_color` |

## 阶段 2：3D 模型与动画表现

1. 在 `base_mods/core/monsters/<id>/` 产出 `<id>.res`（单表面 `ArrayMesh`、`y = 0` 贴地、外法线校验、顶点 `CUSTOM0.w` 写入目标骨骼族）。
2. 新建 `<id>_anim.tres`（`UnitAnimConfig`），调好 `move_phase_scale`、`attack_speed` 与 `flash_color`。
3. 准备图鉴与 2D 回退图标 `icon`（`AtlasTexture` 或独立贴图）。
4. 先在编辑器或终端单刷 1 只确认轮廓、体型比例、配色对比度与弹跳/移动节奏，满意再往下走。

## 阶段 3：专属魂灵与 3D 特效落地

1. 在 `base_mods/core/souls/<soul_id>/` 配置 `<soul_id>_soul.tres`、`<soul_id>_skill.tres` 及所需 `GameplayEffect` / `PassiveTrigger`（能配则不写代码）。
2. 补齐 `tooltip_blocks` 占位符与 `emotion_ranges`，确认见闻和魂器内悬停文案完整。
3. 若新增 3D 命中 Cue 或投射物，按 `指南/特效与Cue.md` 在 `Battle3DBridge` / `BattleFxPool` 接入，并将标签加入 `ModCueRegistrar::BUILTIN_3D_CUE_TAGS`。

## 阶段 4：装配怪物 & 接入地图波次

1. 在 `base_mods/core/monsters/<id>/<id>_monster.tres` 挂载 `mesh_3d`、`anim_config`、`icon` 与 `soul_entries`（魂灵及掉率）。
2. 在 `base_mods/core/mod.json` 的 `souls` 与 `monsters` 列表按字母序注册。
3. 在目标地图的 `MapData` 波次配置中加入该怪物，确保与同图其他怪物的移速、射程与冷却节奏互补。

## 阶段 5：闭环验收

1. **自动门禁**：
   - `python3 tools/lint/runner.py`（0 错误 0 警告）
   - Godot 无头编译检查 `tools/compile_check/check_scene.tscn`（确认 `ModLoader` 无缺失资源、未注册 Cue 或无效 UID 警告）
   - 情景回归测试 `tools/scenarios/run.tscn`（如引入新技能机制，补 1 条情景断言）
2. **真机手感抽查**：
   - 终端单刷 1 只：核对模型比例、移动/攻击动画、血条高度 `hit_height`、击杀碎块 `debris_color`。
   - 终端群刷 50~100 只：核对挤压占位 `body_radius`、帧率与音效/特效密度。
   - 打开见闻图鉴与煤油灯：核对怪物/魂灵图标、掉落与悬停 Tooltip 显示正常。
