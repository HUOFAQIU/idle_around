## 是什么

魂灵是 16 种情绪的混合体。每个魂灵实例携带一份「情绪 → 百分比」的构成，合计 100；魂灵资源声明每种情绪对应的参数范围，构成决定参数落在范围的哪一端。同一种魂灵因此会因情绪不同而产生数值差异，掉落不再只是「有 / 没有」。

情绪影响的是魂灵自身声明的参数；魂灵的本质（例如恐狼「每有一个狼 +20 伤害」）不受情绪影响。

## 16 种情绪

| ID | 名称 | 主要作用 |
|---|---|---|
| `cooldown` | 冷却 | 技能冷却时长 |
| `charge` | 充能 | 给其他魂灵充能 |
| `haste` | 加速 | 加快魂灵冷却 |
| `slow` | 减速 | 减慢魂灵冷却 |
| `sluggish` | 迟缓 | 降低单位移速 |
| `swift` | 迅捷 | 提高单位移速 |
| `freeze` | 冻结 | 停住魂灵或单位 |
| `damage` | 伤害 | 直接伤害数值 |
| `burn` | 灼烧 | 灼烧数值 |
| `poison` | 剧毒 | 剧毒数值 |
| `shield` | 护盾 | 护盾数值 |
| `heal` | 治疗 | 治疗数值 |
| `regen` | 生命再生 | 生命再生数值 |
| `cast_times` | 多重触发 | 一次激活连续释放次数 |
| `max_health` | 最大生命值 | 生命上限 |
| `crit_chance` | 增加暴击率 | 给其他单位增加暴击率，不是魂灵自身暴击率 |

ID 与中文名以 `SoulEmotion` 常量为准。当前只有恐狼声明了情绪范围；其余魂灵不参与情绪系统，数值与模板完全一致。

## 构成与抽签

- 魂灵资源声明「情绪 ID → `Vector2(左端值, 右端值)`」。占比 0 取左端，100 取右端；一个参数只由一种情绪控制。
- **有效情绪** = 声明里除冷却外的项；冷却只进入杂情绪池。冷却对多数魂灵都有用，固定给会过强，因此不保底：抽不到就是范围最慢端。
- 每次生成最多 6 种情绪参与。有效情绪先占位；超过 6 种时随机取 6 种。不足 6 种时，从「16 种减去有效情绪」里随机抽不同种类补满，每种至少 1%。
- 有效情绪总量由地图稀有度决定，在有效情绪之间随机切分；剩余百分比在补进来的杂情绪之间随机切分。
- 有效情绪正好占满 6 种时，100% 全部给有效情绪，不再受稀有度总量区间约束。
- 抽不到某种情绪时，对应参数回落到魂灵模板值（例如冷却读 `SkillDefinition.cooldown_seconds`）。

## 地图稀有度

| 稀有度 | 名称 | 有效情绪总量 |
|---|---|---|
| 1 | 普通 | 20~35% |
| 2 | 精良 | 30~45% |
| 3 | 稀有 | 40~55% |
| 4 | 史诗 | 50~70% |
| 5 | 传说 | 65~85% |

稀有度挂在地图上，而不是魂灵品质上：地图是当前唯一可扩展的难度轴。地图 tooltip 显示稀有度。

## 映射

值 = 左端 + (右端 − 左端) × 占比 / 100。

- **冷却**：范围按左慢右快书写（恐狼 `8 ~ 1` 秒），同一线性公式自然反向；结果落在 1/120 秒刻度。
- **多重触发**：分段按区间步数取整。恐狼范围 `1 ~ 3`，占比 <50 为 1 次、50~99 为 2 次、100 为 3 次。
- **伤害**：映射后向下取整。
- 其他情绪按同一线性公式，后续接入具体参数时再补取整口径。

## 掉落、存档与展示

- 地图战斗的掉落按该地图稀有度 roll；非地图来源按默认稀有度 3。
- 调试时用终端 `soul.roll <soul_id> [rarity]` 生成一颗带构成的实例放进仓库；rarity 省略按默认 3。
- 掉落成功时才实例化并 roll 构成；怪物携带的魂灵继续使用模板固定值。
- 存档只保存魂灵 ID、名字和情绪构成；读档按 ID 恢复魂灵模板后写回构成，未知情绪 ID 丢弃、百分比夹到 0~100。
- tooltip 正文显示实例的实际数值，并新增「情绪」段：列出参与种类与百分比，有效情绪正常色、杂情绪暗色；名称列按显示宽度补齐，百分比列右对齐。
