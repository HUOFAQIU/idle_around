## 1. 定位、尺寸与标签

魂灵不直接装备在角色身上，先放进**魂器**，战斗魂器再装进角色魂器网格（见 `设计/魂器.md`）。魂灵没有部位限制，按占格大小放入魂器内部容器。

- **主动魂灵**：带 `SkillDefinition` 技能与冷却，归零后自动释放；可同时配置 `SoulData.triggers` 触发器。
- **被动魂灵**：`PassiveSoulData` 无冷却、不进自动施法队列、不显示扫描线；装备后占格并阻断左右相邻，提供 `passive_effects`（属性效果）和/或 `SoulData.triggers`（触发效果）。设计目标为“属性效果与触发效果二选一（属性最多 6 条）”，当前代码不做互斥校验。
- **语义类型（`SoulData.types`）**：扁平 `Soul.types.*` 前缀（如 `Soul.types.Wolf`、`Soul.types.Animal`），可多选，用于技能匹配；中文名统一维护在 `scripts/soul_text.gd::SoulText.TYPE_NAMES`。
- **效果标签（`SoulData.tags`）**：`Soul.tags.*` 前缀，供见闻筛选（`Damage` / `DamageReference` / `Burn` / `Poison` / `Freeze` / `Heal` / `Regen` / `Shield` / `Haste` / `Slow` / `Charge`）。
- **尺寸标签（每颗魂灵恰好一个，`ModLoader` 强制校验）**：

| 尺寸标签 | 显示 | 占格 |
|---|---|---|
| `Soul.tags.Small` | `[小型]` | 1 列 × 2 行 |
| `Soul.tags.Medium` | `[中型]` | 2 列 × 2 行 |
| `Soul.tags.Large` | `[大型]` | 3 列 × 2 行 |

## 2. 主动冷却、多重触发与状态规则

“使用魂灵”指技能成功激活（扣冷却、清充能）那一刻，空放也算；被动魂灵没有技能，不算使用。

- **冷却与充能**：默认读 `SkillDefinition.cooldown_seconds`（带冷却情绪时按 `设计/情绪系统.md` 覆盖）；充能直接扣减剩余冷却，超过则立即释放并丢弃溢出。单颗魂灵激活锁为 1/6 秒（1 秒最多 6 次），兜底连环充能。
- **多重触发（`cast_times`）**：一次激活连续释放次数（默认 1，可被情绪覆盖）。每次释放独立选目标、独立判暴击与结算；一次激活只扣一次充能、只广播一次「魂灵被使用」；超出当秒的释放顺延，遇冻结/停战/施法者倒下停止；仅全部释放都未选中目标才记空放。
- **加速 / 减速 / 冻结（作用于魂灵冷却，不改单位移动）**：加速 2× 推进、减速 0.5× 推进、同时存在互相抵消；冻结暂停自然推进，外部充能仍有效且冻结时长照常倒计时。单位级冻结锁整个单位的充能、释放与移动。只有主动魂灵会吃这些状态，被动魂灵免疫但仍阻断相邻。
- **施放顺序**：按角色魂器网格从上到下、从左到右，再按魂器内部从左到右；触发器满充能在帧末按入队顺序释放（实现见 `架构/战斗运行时_施法与冷却.md` §2–§3）。
- **效果结算**：伤害/治疗/护盾/灼烧/剧毒/生命再生的具体公式与取整口径统一以 `架构/战斗运行时_伤害与流程.md` §1 为准。

## 3. 被动魂灵行为边界

- 属性型 `passive_effects` 在开战连接状态日志前挂载到玩家 ASC，不刷「获得状态」日志，最大生命变化按原百分比同步当前生命；详细挂载时序见 `架构/战斗数据与魂灵.md` §4。
- 被动魂灵无来源技能，触发器的 `charge_source_seconds` 被忽略，其余触发效果照常结算；装备两份同名被动魂灵会生成两个独立 `SoulTriggerAbility`，各自计数。

## 4. Tooltip 展示规范

魂灵文案全写在资源的 `tooltip_blocks`（纯文本 + 占位符，不含 BBCode/ANSI），由 `windows/Tooltip/soul_tooltip.gd::SoulTooltip.build()` 统一组装，背包/魂器/见闻复用：

- **结构**：顶部 2 行高跨格标题（魂灵名）→ 尺寸与语义类型行 → `暴击率，X %` → `攻击距离，X`（无主动技能时取触发器 `max_range` 最大值）→ `===================================` 分隔的正文段落 → 情绪构成段（若有）→ 结尾分隔线。
- **占位符**：`{cooldown}`、`{cast_times}`（仅 `>1` 时显示多重触发行）、`{damage}`、`{damage_per_soul}`、`{effect_duration}`，数字禁止硬编码。
- **动态预览（`*` 前缀）**：悬停魂器内 COMBAT 魂灵时，战斗中取 `SoulRuntimeDB` 运行期值，战外按「装上当前魂器」静态预览（仅含 `STATIC` 修正，不含暴击、向下取整）；散装魂灵、TOOL 魂器与见闻只显示基础值。
- **配色与渲染**：状态词配色权威在 `scripts/game_colors.gd`（关键词 → 情绪映射同步见 `设计/情绪系统.md`）；长词优先匹配（`暴击率` 不拆成 `暴击`），单行宽控制在 72 半角列内。终端渲染与格式转换实现见 `架构/窗口与场景.md` §3 与 `架构/终端窗口.md`。
