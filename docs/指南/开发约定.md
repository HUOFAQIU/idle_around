> 代码：`tools/check.sh`

## 1. 环境

| 项 | 路径 |
|---|---|
| Godot 4.7 | `U:\Godot_ver\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64.exe`；无头运行用同目录的 `Godot_v4.7.2-stable_win64_console.exe` |
| 工程 | `U:\Godot_Project\idle_around` |
| Godot 文档 | `U:\Godot_Doc\Godot Engine 4.7 documentation in English MD` |
| GodotGAS Framework | `U:\Godot_Doc\GodotGAS Framework` |
| UE5 GAS | `U:\Godot_Doc\UE5 GAS` |

`tools/check.sh` 的 `GODOT_BIN` 默认指向 console 版；换机器时 `export GODOT_BIN=...` 覆盖，见 `指南/代码检查.md`「一键命令」。

## 2. 开发阶段约定

1. 格式可破坏：存档和设置的格式/内容随功能直接改，不做兼容。
2. 直接替换：旧代码、旧命名、旧迁移和旧文档描述随改动一起删除，新名字只保留一套。
3. 通用容错（如存档 `orphaned`）保留；第三方/上游库和明确保留的占位按原样保留，见 `架构/现状与注意.md` §3「清理保留项」。
4. 无头/自动化测试默认把 `user://` 指到临时目录，只有明确要验证真实存档时才用真实目录。
