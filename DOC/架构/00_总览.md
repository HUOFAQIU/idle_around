> 类型：实现 | 状态：有效 | 核对：2026-11-18

## 1. 项目概览

| 项 | 值 |
|---|---|
| 引擎 | Godot 4.7（Forward Plus / Windows D3D12，MSAA 4×） |
| 主场景 | `Main/Cube/Scenes/main.tscn`（3D 立方体外壳；`Main/control.tscn` 是主视口的 GameUI 覆盖层；01 面存档位、02 面主菜单、04 面角色选择） |
| 帧率 | `run/max_fps=60`；物理帧默认 60 Hz。移动/充能/投射物/吟唱/刷怪/触发器 flush 按固定 tick，GAS 持续效果仍按渲染帧（已知限制，见 `战斗运行时_施法与冷却.md` §1.5） |
| 主窗口 | 单 OS 窗口，全屏透明覆盖层；设计基准 1600×960，游戏 UI 是主视口的全屏 CanvasLayer 覆盖层。01/02/04 面各承载 300×300 的存档位/主菜单/角色选择，默认停屏幕中心；所有面板都是主视口里的 `Control`（BaseWindow），由 `PanelManager` 置顶/激活；面板背景强制不透明 |
| 编辑器插件 | GodotGAS、kanban_tasks、script-ide |

### Autoload

| 名称 | 脚本 | 作用 |
|---|---|---|
| `ModLoader` | `Scripts/mod/mod_loader.gd` | 内置/第三方 mod 发现、校验、PCK 挂载、内容注册；必须排在 `CollectionDB` 之前 |
| `GameGlobal` | `Scripts/GameGlobal.gd` | 全局常量，目前只有主界面默认边距 `WINDOWPOSOFFSET = 5` |
| `GBIS` | `Windows/Inventory/grid_base_inventory_system/core/grid_base_inventory_system.gd` | 背包/仓库/商店系统入口；框架要求全局名必须是 `GBIS` |
| `GameplayCueManager` | `addons/GodotGAS/managers/gameplay_cue_manager.gd` | GodotGAS 的 Cue 管理器；加载内置 registry（当前为空） |
| `ModCueRegistrar` | `Scripts/mod/mod_cue_registrar.gd` | 把 core 和第三方 mod Cue 注册进 `GameplayCueManager` |
| `CollectionDB` | `Scripts/collection_db.gd` | 见闻图鉴：从 ModLoader 构建内容索引、已遇见状态 |
| `CombatTelemetry` | `Scripts/debug/combat_telemetry.gd` | 战斗调试事件记录器：环形缓冲、trace、JSONL 导出；模拟层经 `BattleEventBus` 发事件，适配器转发进来 |
| `SoulRuntimeDB` | `game/battle/soul_runtime_db.gd` | 玩家已装备魂灵的运行期注册表：SoulData 实例 → SoulRuntime |
| `Warehouse` | `Scripts/warehouse.gd` | 仓库分页：启动时预注册 `inventory_0..inventory_9`，提供跨页 `add_item()` |
| `MapBoard` | `Scripts/map_board.gd` | 05 面地图板：8 个已放置地图 + 中心待放地图，提供放置/取下/退回仓库 |
| `SaveManager` | `Scripts/save/save_manager.gd` | 六槽存档门面：`SaveStorage`（按槽 IO/备份）、`SaveScheduler`（去抖）、`SaveDocument`（schema/迁移）与容器/见闻/地图板 participant；启动不自动读档 |
| `GameFlow` | `game/flow/game_flow.gd` | 会话状态（NO_SESSION / CHARACTER_SELECT / IN_GAME）、活动槽/角色、面锁定、新游戏/读档编排 |

### 输入动作

| 动作 | 默认绑定 | 用途 |
|---|---|---|
| `inv_click` | 鼠标左键 | 拿起/放下物品、点击格子 |
| `inv_use` | 鼠标右键 | 使用物品 / 脱下装备（框架内置） |
| `inv_quick_move` | Shift + 鼠标左键 | 在打开着的背包之间快速移动 |
| `inv_quick_sell` | Shift + 鼠标右键 | 商店打开时快速出售仓库物品 |
| `inv_split` | 鼠标中键 | 分割可堆叠物品 |

这些是在 `project.godot` 里配置的鼠标事件，不是键盘按键。

### 各目录职责

| 目录 | 职责 | 备注 |
|---|---|---|
| `Main/` | 主界面入口、状态栏、面板实例 | `control.gd` 负责开关面板，`panel_manager.gd` 负责置顶/激活 |
| `Scripts/` | 全局常量、见闻图鉴服务、mod 加载、Cue 管理、仓库分页、地图板、存档 | `mod/mod_loader.gd`、`mod/mod_cue_registrar.gd`（Autoload 名 `ModCueRegistrar`）、`collection_db.gd`、`warehouse.gd`（`Warehouse`）、`map_board.gd`（`MapBoard`）、`save/save_manager.gd` 是 Autoload |
| `Windows/` | 游戏 UI 与面板交互 | 面板继承 `BaseWindow`（Control）；`TooltipWindow` 是 `PanelContainer` 浮层，`ItemWindow` 是 `Control` 浮层；`ModWindow` 继承 `BaseWindow` |
| `game/battle/` | 战斗逻辑，不依赖具体地图节点 | 只借 `TileMapLayer` 做格子→像素换算 |
| `game/flow/` | 开局会话与面流程 | `GameFlow` autoload；持久化仍归 `Scripts/save/` |
| `game/content/` | 内容脚本、玩家场景、角色定义、Kits、掉落定义 | 魂灵/怪物/魂器/效果/Cue 资源在 `base_mods/core/`，新增时同步改 manifest |
| `base_mods/core/` | 内置官方 mod | `mod.json` + `souls/`、`monsters/`、`vessels/`、`effects/`、`cues/`；只能放 loose 目录，不随导出排除 |
| `mods/` | 示例 mod 源码，按运行时 `res://mods/<id>/` 布局 | 不随正式包导出；用 `modkit/pack_example.gd` 打包 |
| `modkit/` | 示例 mod 的打包工具与说明 | 生成 `user://mods/` 下的 PCK |
| `godot_gas/` | 项目侧 GAS 数据 | 标签注册表、属性集、Cue 注册表 |
| `addons/` | 第三方插件 | 非必要不修改；需要改时先说明 |
| `DOC/` | 设计文档 | 见 `DOC/INDEX.md` |
