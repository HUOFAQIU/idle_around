# E2E 测试

按 `CLAUDE.md` 的三条来：**不写单元测试**、**以 E2E 为唯一验证手段**、**跑完留下可复核可重跑的产物**。
所以这里没有断言内部实现的测试，只有「从真实入口把游戏跑起来、像人一样操作它、把看到的截图存下来」。

## 怎么跑

```bash
"U:/Steam/steamapps/common/Godot Engine/godot.windows.opt.tools.64.exe" --path . res://Tests/e2e_warehouse.tscn
```

跑完会在 `Tests/shots/<场景名>/` 留下（**一个场景一个目录**，不然两个场景的 report.txt 会互相覆盖）：

| 文件 | 是什么 |
|---|---|
| `report.txt` | 每一步做了什么、判定结果、每张图**该长什么样** |
| `NN_名字.png` | 那一步的截图，对着上面的描述看就知道对不对 |
| `.gdignore` | 让 Godot 别把截图当资源扫（不然每张图旁边会多一个 `.import`） |

终端里也会把同样的内容打一遍，最后一行是 `失败 N 条`。

> 前提：跑的时候要有个真窗口（别用 `--headless`），因为要真渲染截图。鼠标会被脚本「借用」：它**不动你的鼠标**，
> 而是把游戏窗口挪到光标底下 —— 所以跑的时候别去碰鼠标，也别把光标挪到屏幕最边上（窗口会摆不下）。

## 现在有哪几个场景

### `e2e_warehouse.tscn` —— 仓库 / 装备窗口

| 步骤 | 在验什么 | 该看到什么 |
|---|---|---|
| 1 | 点主界面「仓库」按钮 → 窗口开 | `01`：第一页六个部位各一件 + 三颗散魂灵 |
| 2 | **落点收边**：按住锁子甲往右拖过头 | `02`：锁子甲跟着光标挂到窗口外，绿框贴在还放得下的最靠右那列 |
| 3 | **装备拖不出仓库窗口**：再拖一次，然后把窗口挪开让光标出去 | `03`：锁子甲还在最右边那列（这次拖动作废了），没被带走 |
| 4 | **右键换装 + 右键卸装**：右键仓库里的弓（换上）→ 右键装备槽（卸下） | `04` 仓库里少一件；`05` 武器槽里有弓；`06` 武器槽空了；`07` 仓库左上角冒出红色的「临」 |
| 5 | **拖魂灵不留残影**：拖一颗魂灵到空行上（放不下）松手 | `08` 拖动中那行浮着魂灵；`09` 松手后跟没拖过**逐像素一样** |

判定只看用户看得见的东西：东西落在哪一格、窗口开没开、临时页按钮出没出现、截图对不对得上。
（测试里读 `grid.pages` 只是为了**找到要操作的那件东西**，不是拿内部状态当断言。）

## 测试台怎么控制鼠标（`e2e_kit.gd`）

Godot 里没法凭空点别的窗口上的按钮，试出来的路子是这三条：

1. **定光标位置 —— 不动鼠标，挪窗口**：`put_cursor_at(win, 窗口内坐标)` 把窗口摆到光标底下。
   App 眼里的「光标在窗口里哪儿」就跟真人操作一模一样。
2. **按下 / 松开**：全局按键状态用 `Input.parse_input_event()` 注入（**要等一帧才生效**，不等的话
   `_process` 会在同一帧把它当成「已松手」），事件本身用 `Window.push_input()` 投递给那个窗口（控件才收得到）。
3. **拖动中移动 —— 还是挪窗口**：窗口往左挪一格，光标在窗口里的位置就右移一格。

### 踩过的坑（改测试时注意）

- **别拖太远**：拖动中「挪窗口」等于让光标在窗口里移动，挪过头就把光标**推出了窗口** ——
  装备一出窗口就被判作废（那是对的行为），测试会莫名其妙地失败。步骤 2 拖 17 格就是这个原因：
  刚好越过收边阈值，光标还在窗口里。
- **截图前要定住冷却线**：魂灵的冷却线每帧都在动，做逐像素比较前得把 `interval` 设大、`cd_progress` 归零。
- **坐标有两套**：格子坐标是 `grid` 局部的，光标要的是**窗口**坐标，中间差着边距 + 分页栏，
  用 `_grid_point()` 换算。
- 右键只要「按下」就能触发（不用等松开），但投递松开也无害。

## 加新步骤

在 `Tests/e2e_warehouse.gd` 里加一个 `_step_xxx()`，在 `_ready()` 里按顺序 `await` 它，
用 `kit.note()` 说清这一步在验什么、`kit.shot(win, "NN_名字", "这张图该看到什么")` 留证据、
`kit.check(...)` 判可见的结果。跑完 `kit.finish("标题")` 会写报告。

场景名在建 kit 时就定了：`var kit := E2EKit.new("windows")` —— 产物就落在 `Tests/shots/windows/`。

场景复杂到要拆文件时，复制 `e2e_warehouse.tscn` 改个名即可（root 是 Control，`_ready()` 里
`load("res://control.tscn")` 起真实主场景）。
