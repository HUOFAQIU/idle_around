# 冷却 cooldown

固定游戏为 60 帧，每帧充能为 1/60，1 秒获得 1 秒当前冷却
被加速时，在加速时间内，每帧充能为 2/60，1 秒获得 2 秒当前冷却
被减速时，在减速时间内，每帧充能为 1/120，1 秒获得 0.5 秒当前冷却
同时被加速减速时，相互抵消，不受影响，每帧充能为 1/60，1 秒获得 1 秒当前冷却
被充能时，获得（被充能数值）秒当前冷却

当当前冷却等于主动技能冷却时，释放技能
当被充能数值大于剩余冷却时，直接释放技能，溢出的被充能数值不会影响下次冷却
