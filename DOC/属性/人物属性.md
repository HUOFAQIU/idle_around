# 人物属性

文件：`godot_gas/attributes/player_stats_attribute_set.gd`

| 属性 | 说明 |
|---|---|
| `max_health` | 最大生命值；`health` 的上限 |
| `health` | 当前生命值，钳制在 `[0, max_health]` |
| `damage_bonus` | 己方魂灵直接伤害加成（固定值，默认 0） |
| `burn` | 当前灼烧层数；每 0.5 秒按整数层数结算并衰减 3% |
| `shield` | 当前护盾值；优先承伤，无上限、无持续时间 |
| `poison` | 当前剧毒值；每秒与再生相减后按净值结算，无视护盾 |
| `regen` | 当前生命再生值；每秒与剧毒相减后按净值恢复生命 |

怪物使用 `monster_stats_attribute_set.gd`，属性相同，没有 `damage_bonus`。
