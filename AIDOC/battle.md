# 战斗

目前装备系统还没做，因为优先级没战斗高，我想先看下表现。

## 需求
- 玩家控制的角色在正中间，为 `PlayerToken`。
- 只需要一个很简单的场景，在距离 10 以外生成怪物，怪物资源用 `tokens.png` 内 (64, 0)、大小 (32, 32)，每 3 秒随机位置生成一个，怪物 hp 100，每 3 秒会往 `PlayerToken` 的位置移动 1 格。
- `PlayerToken` 只会一个能力，每 2 秒发射一个投射物，资源用 `tokens.png` 内 (0, 32)、大小 (32, 32)，投射物伤害 30。
- `PlayerToken` hp 500。
- 投射物命中怪物时，怪物身上会跳数字，为伤害的数值。
- 如果 `PlayerToken` hp <= 0，显示角色死亡，在 3 秒后复活。
- 设计不要复杂，简单明了就行。

## 需求里没写、后来定下来的
| 问题 | 定下来的做法 |
|---|---|
| 玩家怎么掉血 | 怪物走到玩家**相邻**的格子就停下、不再往里挤，每 3 秒咬 20 点 |
| 投射物打谁、怎么飞 | 打**最近的**怪，直线飞过去、碰到就爆；怪中途挪开就可能打空 |
| 死亡那 3 秒 | **清空场上所有内容**（怪、投射物、伤害数字），3 秒后满血复活 |

## 现在是什么样【已定】

| 项 | 值 | 在哪 |
|---|---|---|
| 棋盘 | 1050 格六边形，距中心最远 22 格 | `Windows/tile.tscn` |
| 刷怪 | 每 3 秒 1 只，随机落在**距离 > 10** 的格子上（这样有 720 个候选格） | `SPAWN_MIN_DISTANCE` |
| 怪物 | hp 100，红色色块，`tokens.png` (64, 0) | `monster.gd` |
| 怪物移动 | 每 3 秒所有怪一起朝中心走 1 格，走一格花 0.15 秒 | `TURN_INTERVAL` |
| 怪物攻击 | 贴到距离 1 就停下，每 3 秒咬 20 点 | `BITE_DAMAGE` |
| 玩家 | 钉在中心 `(0,0)` 不动，hp 500 | `PLAYER_MAX_HP` |
| 玩家攻击 | 每 2 秒朝最近的怪发射投射物，伤害 30 | `FIRE_INTERVAL` |
| 投射物 | 300 像素/秒，直线飞不追人，飞 3 秒没打中就消失 | `projectile.gd` |
| 命中 | 怪身上跳伤害数字，怪闪一下 | `_pop_damage()` |
| 死亡 | hp ≤ 0 → 清场 + 显示「角色死亡」→ 3 秒后满血复活 | `_die()` / `_revive()` |
| 暂停 | 窗口没开着时整场暂停 | `_physics_process()` 判 `visible` |

几个实现上的注意点：
- **一个 3 秒心跳**同时干三件事：所有怪朝中心挪一格 → 贴脸的咬一口 → 刷一只新的。所以怪是整齐地一跳一跳走
- **一格只站一只怪**：前面有怪挡着就原地等一拍，怪会排成一列列往里推，所以能咬到玩家的最多 6 只（距离 1 那一圈）。被挡住的怪不会绕路
- 怪和投射物都是 **Sprite2D 节点**（跟 `PlayerToken` 一样），不是图块。`EnemyTileMapLayer` 现在没用上
- 投射物的图是个朝上的箭头，飞行时会 **旋转到飞行方向**；一帧分小步飞，免得帧一卡就从怪身上穿过去
- 左上角有个 **`1×` / `10×` 的开发用加速按钮**，走 `Engine.time_scale`（整个游戏一起快，不只是战斗）；窗口一关自动还原成 1 倍
- 格子上的距离数字是调试用的，现在关着：`SHOW_DEBUG_DISTANCE = false`
