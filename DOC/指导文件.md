# 指导文件

> 类型：指南 | 状态：有效
> 何时读：要把一次纠正变成规则，或判断规范该放代码还是文档时
> 关键词：lint、规则、注释、代码库、易错 API
> 代码：`tools/lint/`、`tools/check.sh`
> 相关：`指南/代码检查.md`
> 核对：2026-11-15

1. 每纠正 AI 一次，就把这次纠正写成 lint 这类自动检查规则，少往 agents.md 这类说明文档里加话。违反 lint 规则的代码会直接报错、提交不上去，文档里的话 AI 不一定照做。
2. 代码库是 AI 最主要的学习材料。里面的坏写法、临时补丁，会被下一个 AI 当成惯例照抄，像杂草一样越长越多，所以代码库要保持干净。
3. 容易用错的东西，直接禁掉。
4. 禁掉 99% 的代码注释。AI 爱在注释里给自己走的捷径找理由，后来的 AI 就照着学。她在 Cursor 时，这种“有理由的补丁”扩散开来，把应用拖得很卡。
