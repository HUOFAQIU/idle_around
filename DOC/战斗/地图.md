# 地图机制
地图应该是物品，占 2*2，UI暂且和魂灵一样，文字显示地图：xx，比如，地图：森林，res://Assets/map_22.png
每张地图（现在就一张，就叫森林）刷什么怪物需要配置，以现在森林为例
```
地图: 森林

怪物配置（名称，配置数量，刷怪条件）
蛇，200，每 1 秒
蝮，0，击杀 10 蛇
```
Tooltip显示如下，根据配置显示
```
森林

每 1 秒出现蛇
每累计击杀 10 蛇时，出现蝮
```
在立方体 05面，同样有 9 个方格
中心是一个可以放置地图的空槽，可以将地图拖入
从左上角开始，顺时针，生成放置地图的按钮，空槽中地图消失。左键点击开启战斗窗口，和存档一样，右上角按钮，显示⬇，点击地图被回退到仓库
位置不够时，提示地图集已满，不会生成相应按钮，空槽中地图也不会消失
战斗可以无限死亡，地图不会被消耗
怪物都击杀完，这张地图就算完成了，等待 5 秒后，会自动重新开始这张地图。

# 数量石
游戏内应该存在一些物品，能够强化地图，就像《POE》里的崇高石
数量石，占 1*1，UI暂且和魂灵一样，文字显示数量石，res://Assets/item_11.png
Tooltip显示如下
```
数量石

怪物数量 +50%
```
这里怪物数量 +50%，就是蛇的数量 +50%，不会影响后续刷出的怪物数量。
