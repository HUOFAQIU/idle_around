终端目前是“字符网格渲染 + 固定屏幕缓冲”的显示层，主界面「终端」按钮打开 `TerminalWindow`，内容区铺满 `TerminalView`。ANSI SGR 已接入；键盘输入还没接。

## 1. 分层

| 层 | 文件 | 职责 |
|---|---|---|
| 调色板 | `Scripts/terminal/terminal_palette.gd` | 16 色 ANSI 色板 + 默认前景/背景 |
| 样式 | `Scripts/terminal/terminal_style.gd` | 单格样式：fg/bg/bold/underline/reverse |
| 宽度 | `Scripts/terminal/terminal_width.gd` | 近似 wcwidth：1/2/0 列；CJK、全角、emoji 双宽，组合字符 0 宽 |
| ANSI 解析 | `Scripts/terminal/terminal_ansi_parser.gd` | 流式状态机：SGR 颜色/样式、256 色、truecolor；其他 CSI/OSC 跳过 |
| 缓冲 | `Scripts/terminal/terminal_buffer.gd` | 并行 Packed 数组存字符/颜色/属性；写入、换行、滚动、resize；双宽字符占两格 |
| 历史 | `Scripts/terminal/terminal_history.gd` | 滚出屏幕的行按行环保存，默认 1000 行；支持列数变化重建 |
| 渲染 | `Windows/Terminal/terminal_view.gd` | `Control._draw()` 把历史和实时屏幕拼成可见窗口；背景 run、字形、下划线、光标；滚轮回看 |
| 跨格大字 | `Scripts/terminal/terminal_span.gd` | 一行文本占 N 行网格的描述；由 `TerminalView` 按字体度量绘制 |
| 窗口 | `Windows/Terminal/terminal_window.gd` | `BaseWindow` 外壳；欢迎信息；只显示 |
| 预览 | `Windows/Terminal/terminal_preview.tscn` | 独立 demo：16 色、样式、光标、打字、滚动、调试网格/悬停 |

写入路径：外部 → `TerminalView.write_line()` / `write_ansi()` → `TerminalBuffer` → `queue_redraw()`。ANSI 解析在独立 Parser 里，Buffer 和 View 都不认识转义文本；输入也应该做成独立中间层。

## 2. 已实现

- 16 色 ANSI 调色板，颜色值与参考网页 how-terminals-work 一致。
- 单格前景/背景色、粗体、下划线、反显。
- 整行写入、`\n`/`\r`/`\t`/`\b`、满列待换行、到底部整屏上滚。
- 光标块状反色、0.5 秒闪烁；写入后重置闪烁。
- 窗口 resize 时按 cell 尺寸重算行列，内容保留左上角。
- 行环形缓冲：上滚只移动行起点并清空新底行；逻辑行通过 `TerminalBuffer.get_row_base(row)` 读取。
- CJK/全角双宽：Buffer 用 `ATTR_WIDE` + `WIDE_CONTINUATION` 占两格，光标/退格/resize 都按宽度处理；渲染器用 `cjk_font` 画宽字符并按两格居中。
- 系统中文字体 fallback：`TerminalView` 自动找 Microsoft YaHei UI / Microsoft YaHei / Noto Sans CJK SC / Sarasa Mono SC 等；没有时中文仍会缺字。
- ANSI SGR：`TerminalAnsiParser` 支持 `0/1/4/7/22/24/27`、`30–37/39/40–47/49/90–97/100–107`、`38;5;n`/`48;5;n`、`38;2;r;g;b`/`48;2;r;g;b`；样式跨 `write_ansi()` 调用保持，未完成的序列会挂到下一次继续解析。
- 回看历史：`TerminalHistory` 保存滚出屏幕的行，默认上限 1000 行；`TerminalView` 用 `view_offset` 把历史和实时屏幕拼成可见窗口，滚轮向上翻历史、向下回底部；滚到历史时隐藏光标。
- 自动滚底：`auto_scroll` 默认开启；用户上翻后暂停，新内容会按新增行数抬高 `view_offset` 保持当前观感；回到底部或调用 `scroll_to_bottom()` 恢复。
- 显示 API：`set_content(lines)` / `set_ansi_content(lines)` / `append_line()` / `append_ansi_line()` / `clear()` / `scroll_to_bottom()` / `scroll_by()`；`TerminalWindow` 转发 `set_content` / `append_line`，窗口还没布局时先缓存。`fit_text(text, reserved_rows := 0, min_cols := 1)` 按纯文本计算行列、设置最小尺寸并重建缓冲，供 Tooltip 自动尺寸使用；`reserved_rows` 给顶部跨格大字留空行，`min_cols` 保证标题不被正文裁窄。`set_content()` / `set_ansi_content()` 的 `start_row` 指定正文从哪一行开始写。`transparent_background = true` 时不画终端背景，露出父面板底色。
- 跨格大字：`TerminalSpan` 表示一行文本占多行（`text / row / col / rows / style`），`TerminalView.set_spans()` 绘制、`clear_spans()` 清除、`measure_span()` 计算占用网格。字号按块高和字体行高反推，每个字按实际 advance 计算列宽并居中；Buffer 对应格子由调用方留空，普通字形/光标会跳过这些格子，调试网格跳过 span 内部的分隔线。当前是 View 级装饰，不参与 Buffer 历史、光标和选中。
- Tooltip 适配：仓库/见闻悬停的 `TooltipWindow` 正文已换成内嵌 `TerminalView`；输入是 `SoulTooltip` / `VesselTooltip` 的 PLAIN 文本，`TooltipWindow` 转成 ANSI 后按字符网格显示（truecolor 对应 `GameColors`，冷却行用粗体代替 20 号字）。标题也由同一个 `TerminalView` 用顶部 `TerminalSpan` 绘制（2 行高，带下划线，画在 span 块底部），不再使用 `Label`。`TestAPI.terminal_show_soul_tooltip()` 等仍可把 tooltip 写进终端窗口。
- 调试网格：`TerminalView.debug_grid` 在格边界画低透明度线，主终端窗口默认开启；预览场景用独立 `DebugOverlay`（带悬停格子），两边共用 `TerminalView.DEBUG_GRID_COLOR`。
- 独立预览场景，带网格线/悬停格子调试 overlay 和「回到底部」按钮。
- `TestAPI.terminal_write_line()` / `terminal_write_ansi()` / `terminal_set_content()` / `terminal_set_ansi_content()` / `terminal_scroll()` / `terminal_scroll_to_bottom()` / `terminal_clear()` / `terminal_snapshot()` / `tooltip_snapshot()`。

## 3. 已知限制

- 组合字符（宽度 0）目前直接跳过，带重音的拉丁文字、阿拉伯文组合等会丢失附加符号。
- emoji ZWJ 序列、区域旗帜等复合字形没有组合渲染；每个码点仍按独立字符处理。
- 中文字体依赖系统：当前自动找 Microsoft YaHei UI 等，换机器或系统没有这些字体时中文仍会缺字；还没有打包可分发字体。
- ANSI 只支持 SGR；CSI 光标移动/擦除/备用屏目前整段忽略，冒号子参数和 dim/italic/blink/strikethrough 未实现。
- 回看历史默认 1000 行，超过后丢最旧行；`scrollback_lines = 0` 可以关闭历史。
- 终端按列硬换行，不做英文单词级 word wrap；长单词会被拆开。
- 滚到历史时光标隐藏；上翻后新内容不会自动拉回底部（`auto_scroll = false`）。
- 没有键盘输入、命令、选区复制；`TerminalWindow` 和 `InfoWindow` 也没有滚动条，回看历史只能用滚轮。
- 终端正文使用统一 cell 字号；Tooltip 的冷却行用粗体代替 20 号字。标题用 `TerminalSpan` 按 2 行高临时放大，字号不是固定 24 号。
- `TerminalSpan` 只是 View 级装饰：不进入 Buffer/历史，不参与选中复制；ANSI 也没有纵向跨格标准，所以多格大字只能走 `TerminalView.set_spans()` 专用 API，`TooltipText.ANSI` 仍然只负责正文。
- 每次写入/光标闪烁仍整屏重绘；当前没有脏行裁剪。
- 没有备用屏幕、鼠标上报、能力探测，也没有 PTY；这些只有做“真终端模拟器”才需要。

## 4. 功能路线

### 定位（2026-11-14 调整）

终端定位为**游戏内内容的显示载体**，类似 `TooltipWindow` / `InfoWindow`：只负责把内容排成终端样式，不做交互式 shell。键盘输入、命令注册表、raw 模式、备用屏暂缓，等确定要做控制台再加。

首用方向确定为**通用显示 API**（滚动回看、自动滚底、set/append 内容）；Tooltip 的 ANSI 输出和战斗日志（`InfoWindow`）已接入，其他内容来源待定。

已完成（2026-11-14）：CJK 双宽 + 系统中文字体 fallback、ANSI SGR、回看历史 + 自动滚底、显示 API、Tooltip ANSI 适配、战斗日志 InfoWindow 终端化。

### P0：显示载体

1. **内容适配层**
   - Tooltip（已完成）：`TooltipText` 增加 ANSI 序列化，终端不解析 BBCode；`TooltipWindow` 正文已换成内嵌 `TerminalView`，仓库/见闻悬停直接按字符网格显示，标题用顶部跨格大字；`TestAPI.terminal_show_soul_tooltip()` / `terminal_show_vessel_tooltip()` / `terminal_show_equipped_vessel_tooltip()` 可把同样内容写进终端窗口。
   - 战斗日志（已完成）：`BattleLogAdapter` 仍把 `(text, color)` 交给 `InfoWindow.append_line()`；`InfoWindow` 正文是 `TerminalView`，保留原窗口、☰ 开关和 600×428 尺寸。日志在窗口隐藏时写入 500 行缓冲，打开时重建到终端，可见时直接追加；颜色用 `Color.from_string()` 转 `TerminalStyle.fg`，终端底黑、光标和调试网格关闭。
   - 纯文本/ANSI：`set_content` / `set_ansi_content` / `append_line` 直接可用。
2. **排版约定**
   - 终端按列硬换行；长英文单词、宽字符由内容适配层处理，不做自动 word wrap。
   - 标题/分隔线/缩进由内容适配层拼，不塞进 Buffer。

## 5. 性能路线

行环形缓冲和历史行环已完成。历史 push 每行 O(cols)，和清空新底行同量级；默认 1000 行在 90 列下约 3.3 MB（每格 4 + 16 + 16 + 1 字节）。历史实测（本机 GTX 1060 / GL Compatibility 时期 / 关闭 vsync；现已切 Forward+，数值需重测）：

| 场景 | 结果 |
|---|---|
| Buffer 120×42 连写 2000 行 | 168 ms，84 µs/行（行环前 1195 ms，598 µs/行） |
| Buffer 192×56 连写 2000 行 | 205 ms，102 µs/行 |
| 1200×800 整屏重绘 | 约 2.3 ms |
| 1920×1080 整屏重绘 | 约 3.6 ms |
| 900×600 游戏内终端（90×31） | 约 1.5 ms/帧 |

结论：900×600 面板 60fps 够用；1080p 满屏约 3.6 ms 还能接受；4K 全屏约 13 ms，需要继续优化。

剩余优化按收益排序：

| 优先级 | 优化 | 预计收益 | 何时做 |
|---|---|---|---|
| 1 | 按样式 run 画字：同色/同样式连续 cell 合并成 `draw_string`/`TextLine` | 1080p 3.6 → 1.5–2 ms；4K 13 → 5–6 ms | 全屏/4K |
| 2 | 脏行重绘：每行一个绘制层或行缓存 | 单行追加 3.6 → 0.1–0.2 ms | 高频日志/滚动 |
| 3 | ASCII 快速写入：`to_ascii_buffer()` + 内联写格 | 84 → 25–40 µs/行 | 每秒几百行以上 |
| 4 | 紧凑 cell 存储：样式表 + 每格样式索引 | 内存减半，缓存更好 | 4K/大 scrollback |
| 5 | 光标独立层 | 每 0.5 秒省 2–3.6 ms | 锦上添花 |
| 6 | MultiMesh / 字形图集 | 4K 60fps 轻松 | 只做真终端模拟器时 |

## 7. 常见排查

| 现象 | 检查点 |
|---|---|
| 中文不显示/错位 | 先看 `TerminalView.cjk_font` 是否找到系统字体（Microsoft YaHei UI / Noto Sans CJK SC 等）；再检查 `TerminalWidth.columns()` 是否返回 2，以及续格是否在写入/覆盖/resize 时被清掉 |
| ANSI 颜色不生效/原样显示 | 确认用 `write_ansi()` / `write_ansi_line()` / `TestAPI.terminal_write_ansi()`，而不是 `write_text()`；目前只解析 SGR，其他 CSI 会被整段吞掉 |
| 终端窗口很小/网格只有几列 | 视口是否异常小；`BaseWindow` 会用 1600×960 兜底，但 headless dummy 视口可能是 64×64 |
| 写入后不刷新 | 确认走 `TerminalView.write_line()`/`write_text()`/`write_ansi()`，不要直接改 Buffer 数组 |
| 滚动后内容错位 | 读逻辑行必须用 `TerminalBuffer.get_row_base(row)`，不能再用 `row * cols` |
| 滚轮没反应 | `TerminalView.mouse_filter` 不能是 `IGNORE`；预览里的 DebugOverlay 用 `PASS` 把滚轮让给父级；history 为 0 时也没有历史可翻 |
| 上翻后新内容把视图拉回/停不住 | 检查 `auto_scroll`；`write_*` 在 `auto_scroll=false` 时会按新增行数抬高 `view_offset`，回底部用 `scroll_to_bottom()` |
| 历史行丢失 | 默认上限 1000 行，超过丢最旧行；改 `TerminalView.scrollback_lines` 或设 0 关闭历史 |
| 滚到历史后看不到光标 | 设计如此：`view_offset > 0` 时隐藏光标 |
| Tooltip 文本行首被覆盖/冷却行没加粗 | 文本里是否带 `\r`；`TooltipText` 会统一 CRLF → LF，绕过它自己拼 ANSI 时要先处理换行 |
